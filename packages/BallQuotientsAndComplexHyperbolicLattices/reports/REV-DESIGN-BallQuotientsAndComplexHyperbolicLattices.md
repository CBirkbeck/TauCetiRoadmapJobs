1. **F01** (P2) §8.1 calls the twist χ a unitary character; it is only a semi-character

   Location: `packages/BallQuotientsAndComplexHyperbolicLattices/design/README.md` line 554, "where n_{(a,t_a)} ∈ Γ_b and χ(a) = e^{2πit_a/τ} is a unitary character twist"; `design/plan.json` target 8.1 statement ("with |χ(a)| = 1" is fine, "character" is not).

   Claim: a ↦ χ(a) = e^{2πi t_a/τ} is a character of Λ_b.

   Witness (computed): from the group law of N, the element over a + a′ is (a,t_a)·(a′,t_{a′}) = (a + a′, t_a + t_{a′} − 2 Im⟨a,a′⟩), so χ(a + a′) = χ(a)χ(a′)·e^{−4πi Im⟨a,a′⟩/τ}. The commutator of n_{(a,·)} and n_{(a′,·)} is T_{−4 Im⟨a,a′⟩} ∈ Γ ∩ Z(N) = ⟨T_τ⟩, so 4 Im⟨a,a′⟩ ∈ τℤ and the correction factor is ±1, equal to −1 when 4 Im⟨a,a′⟩/τ is odd. Instance, n = 2, λ > 0 real: Δ = ⟨n_{(λ,0)}, n_{(iλ,0)}⟩ is a lattice in N with Δ ∩ Z(N) = ⟨T_{4λ²}⟩ (the commutator), so τ = 4λ² and Λ = ℤ[i]λ; the element over (1+i)λ is n_{(λ,0)}·n_{(iλ,0)} = ((1+i)λ, −2 Im(λ·iλ)) = ((1+i)λ, −2λ²), so χ((1+i)λ) = e^{2πi(−2λ²)/(4λ²)} = −1 while χ(λ) = χ(iλ) = 1. Not multiplicative.

   What survives: the multipliers e_a(u) = χ(a)e^{−(4π/τ)⟨a,u⟩ − (2π/τ)|a|²} do form a holomorphic factor of automorphy (they are the action of the group Λ_b ≅ Γ_b/⟨T_τ⟩, and e_{a+a′}(u) = e_a(u + a′)e_{a′}(u) holds with the ±1 absorbed by e^{(4π/τ)i Im⟨a,a′⟩}), μ is invariant, L_b is a negative line bundle, and nothing in §§8.2–9.5 uses multiplicativity of χ. The error is a false identification of an object, not a broken construction.

   Repair (tested on the instance above): in §8.1 replace "is a unitary character twist" by "is a unitary semi-character: χ(a + a′) = χ(a)χ(a′)e^{−4πi Im⟨a,a′⟩/τ}, the exponent being ±1 because 4 Im⟨a,a′⟩ ∈ τℤ by §6.4; χ is a character exactly when [Γ_b, Γ_b] ⊆ ⟨T_{2τ}⟩". Add the Check: "For n = 2 and Γ_b = ⟨n_{(λ,0)}, n_{(iλ,0)}⟩, τ = 4λ², χ(λ) = χ(iλ) = 1 and χ((1+i)λ) = −1: a definition of L_b that assumes χ multiplicative would use the wrong gluing over (1+i)λ." Change the plan.json statement of 8.1 accordingly. (The same slip is in the source; see Source issues.)
