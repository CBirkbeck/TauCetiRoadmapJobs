**The own arguments of the two paragraphs, recomputed.** (a) In ZF a universe `U` (UA1–UA5) equals `V_κ` for `κ = U ∩ Ord` (an ordinal, `U` being transitive). `V_κ ⊆ U`: by induction on `β < κ`, `V_β ∈ U`: `V_0 = ∅ ∈ U` (some `x ∈ U`, `∅ ∈ powerset x ∈ U`, UA1); `V_{β+1} = powerset V_β ∈ U` by UA2; at a limit `β < κ`, `β ∈ U` and `V_β = ⋃_{γ ∈ β} V_γ ∈ U` by UA4. `κ` is a limit: `β ∈ U` gives `β + 1 ⊆ powerset β ∈ U`, so `β + 1 ∈ powerset (powerset β)` and `β + 1 ∈ U` by UA1. `U ⊆ V_κ`: an `∈`-minimal `x ∈ U \ V_κ` has `x ⊆ V_κ`; the family `y ↦ rank y`, `y ∈ x`, is indexed by `x ∈ U` with values in `κ ⊆ U`, so its union `sup_{y ∈ x} rank y` is an ordinal in `U` by UA4, hence `< κ`, hence `rank x ≤ sup + 1 < κ` and `x ∈ V_κ`: contradiction. `rank` is definable by well-founded recursion, so no choice is used; the inputs are UA1, UA2, UA4 (and UA5 for `∅`), as the paragraph says. (b) `V_κ` is a universe when `κ` is v-inaccessible: UA1 as `V_κ` is transitive; UA2 since `κ` is a limit (Proposition 4 (2): a regular uncountable cardinal); UA3 trivially; UA4 from second-order replacement (the image of `I ∈ V_κ` under any `f` is in `V_κ`) and the union axiom of `V_κ`; UA5 as `∅ ∈ V_κ`. (c) The 2.3 paragraph: Cohen forcing has `Card(P) = ℵ₀ < κ` for every inaccessible `κ` of the ground model, so Corollary 16 applies to each of them in the symmetric submodel `N`; a set `x ∈ N` of rank `α` lies in `V_κ^N` for a ground inaccessible `κ > α` (a proper class of them), which is a universe in `N` by (b); `P(ω)` is not well-orderable in `N` by Theorem 17. So `ZF` + "every set lies in a universe" does not prove choice (relative to the consistency of ZFC with a proper class of inaccessibles), while ZF + Tarski's A does (Tarski 1939, p. 182).
