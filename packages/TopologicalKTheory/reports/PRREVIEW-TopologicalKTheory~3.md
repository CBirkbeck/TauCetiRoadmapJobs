## R02 (P3) — A T3.3 Check justifies properness with a false clause

**Location.** `README.md` lines 993–995: "The projection ℝ→pt is not proper, and the trivial line has no compactly supported class on ℝ since Kc(ℝ)=0, so no pullback along it exists".

**Claim.** The trivial line over ℝ has no class in `Kc(ℝ)`.

**Witness.** A compactly supported class on ℝ is a triple `(E,F,σ)` with σ an isomorphism off a compact set (T3.3, line 980); `(1,1,id)` is such a triple, its class is 0, and `Kc(ℝ)=0` says every class is that one. So the trivial line has a compactly supported class, namely 0; what fails is that no functorial pullback along a non-proper map exists (for the open inclusion ℂ∖{0}→ℂ, say, restriction of the generator β of `Kc(ℂ)` to ℂ∖{0} is not compactly supported data, since the trivialization of L off a compact set of ℂ does not restrict to one off a compact set of ℂ∖{0}).

**Repair.** Replace the clause by the correct reason: "The projection ℝ→pt is not proper, so no pullback `Kc(pt)→Kc(ℝ)` is defined; a definition that pulled back along every map would send 1∈Kc(pt)=ℤ to the trivial line with no trivialization off a compact set, which is not compactly supported data". The rest of the bullet (closed embedding ℝ→ℝ² proper; open inclusion ℂ→S² with extension `Kc(ℂ)=ℤβ→K(S²)` injective, generator to β) is correct (table row 15).
