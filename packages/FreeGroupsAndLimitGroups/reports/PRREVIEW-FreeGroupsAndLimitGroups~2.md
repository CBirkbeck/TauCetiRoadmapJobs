## R01 (P2) — §7.7 is recursive only for a fixed rank, but §7.11 needs it uniformly in the rank

**Claim:** A positive sentence with `k` universal variables is decided by constrained satisfiability over `F(A ∪ {x₁,…,x_k})`, whose rank grows with the sentence. A recursive set for each fixed rank does not give one recursive set of sentences, so §7.11's conclusion has no supplier. This is the same gap that the head closes for the number of variables.

**Witness:** IFT line 1146–1147: the proof of Corollary 9 decides equations with constraints `y_i ∈ F[X_i]` over `F[X]`. `∀x∃y (y²=x)` over `F(a,b)` needs rank 3. In `Suggested.lean:69`, `n` lies outside `ComputablePred`.

## R02 (P2) — The Grushko-decomposition headline can be stated at the pins but is absent from `Suggested.lean`

**Location:** `TauCetiRoadmap/FreeGroupsAndLimitGroups/README.md:5` "finite Grushko and JSJ decompositions of finitely generated fully residually free groups … (Layer 10)"; `Suggested.lean:24–31`, which names only §§7.8, 7.11, 10.2, 10.7 and 11.6 as not statable.

**Claim:** §4.11(3) and §10.4 can be stated with Mathlib's `Monoid.Coprod`, `Monoid.CoprodI` and `FreeGroup`. The file neither states them nor says that they cannot be stated.

**Witness:** The three declarations below elaborate in a scratch file importing only Mathlib, with three `sorry` warnings and no other diagnostic. They are not vacuous: trivial `G` has `p=q=0`, `ℤ` has `p=0,q=1`, and `ℤ²∗F₂` has `p=1,q=2` (§4.11).

**Repair:** Add to `Suggested.lean` (Layer 4 section):
```lean
/-- A group is freely indecomposable when it is nontrivial and is not the internal free product
of two nontrivial subgroups (§4.11). -/
def IsFreelyIndecomposable (G : Type*) [Group G] : Prop :=
  Nontrivial G ∧ ∀ A B : Subgroup G,
    Function.Bijective (Monoid.Coprod.lift A.subtype B.subtype) → A = ⊥ ∨ B = ⊥

/-- Grushko decomposition (§4.11(3)): a finitely generated group is the internal free product of
finitely many freely indecomposable subgroups, none infinite cyclic, and a free group of rank `q`. -/
theorem exists_grushko_decomposition (G : Type*) [Group G] [Group.FG G] :
    ∃ (p q : ℕ) (H : Fin p → Subgroup G) (t : Fin q → G),
      (∀ i, IsFreelyIndecomposable (H i) ∧ ¬ (IsCyclic (H i) ∧ Infinite (H i))) ∧
      Function.Bijective
        (Monoid.Coprod.lift (Monoid.CoprodI.lift fun i => (H i).subtype) (FreeGroup.lift t)) := by
  sorry
```
Also add `grushko_decomposition_unique`: given two such decompositions `(H, t)` and `(H', t')`, conclude `q = q' ∧ ∃ σ : Fin p ≃ Fin p', ∀ i, ∃ g : G, H' (σ i) = MulAut.conj g • H i` (it elaborates under `open Pointwise`). In README §4.11, after "Statement (2) is `rank_coprod`.", add "Statement (3) is `exists_grushko_decomposition` and `grushko_decomposition_unique`, with freely indecomposable groups given by `IsFreelyIndecomposable`."
