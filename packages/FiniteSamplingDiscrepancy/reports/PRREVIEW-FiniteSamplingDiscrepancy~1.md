## R01 (P2) — Total-variation API cited from Mathlib and from MarkovChainsAndRenewal does not exist at the pin

**Location.** `TauCetiRoadmap/FiniteSamplingDiscrepancy/README.md` lines 24–26 ("owns the formula `tvDist μ ν = ∑' y, …`"), 39–41 ("Use Mathlib's signed normalization: `etvDist P Q = ENNReal.ofReal (tvDist P Q)`"), 54–57 (`etvDist_map_le`, "naming as `tvDist_map_le` in Mathlib PR #27579"), and every `tvDist`/`etvDist` statement in L1.3, L2.4, L3.1–L3.3, L4.1 and the worked examples.

**Claim.** The roadmap's headline formulas are stated in Mathlib's `tvDist`/`etvDist`, its L0.4 is a Mathlib contraction lemma, and the countable-space formula is consumed from MarkovChainsAndRenewal Layer 3 item 5.

**Witness.** At the pinned Mathlib, `grep -rn tvDist Mathlib` returns 0 files; at the pinned Tau Ceti, `grep -rn etvDist TauCeti` returns 0 files. MarkovChainsAndRenewal's item 5 (its README line 261) itself cites "Mathlib's `MeasureTheory.tvDist` (mathlib4 #37730)", i.e. the same unpinned declaration, so that supplier citation resolves to nothing at the pin either. `Suggested.lean` lines 17–22 admit this ("That pin predates Mathlib's `etvDist` / `tvDist` …; those are available in newer … sources"), which is exactly the drift the review rules exclude: a library declaration is cited at the pin or not at all.

**What the pin does have.** Tau Ceti `TauCeti/MeasureTheory/VectorMeasure/Decomposition/Jordan.lean`: line 91 `Measure.toJordanDecomposition_toSignedMeasure_sub_posPart_univ_eq_iSup` (the positive part of `μ.toSignedMeasure − ν.toSignedMeasure` on `univ` equals `⨆ A measurable, μ A − ν A`), line 112 `totalVariation_toSignedMeasure_sub_univ_le`, line 141 `totalVariation_toSignedMeasure_sub_univ_le_two_mul_iff` (for equal total mass, TV on `univ` `≤ 2c` iff every event satisfies `μ A ≤ ν A + c`). The probe `example … := Measure.toJordanDecomposition_toSignedMeasure_sub_posPart_univ_eq_iSup` elaborated against the pin. Tau Ceti's own finite de Finetti TV corollary at the pin is stated in this carrier (`FiniteDeFinetti.lean` line 261). **Repair.** (1) In Conventions, define the roadmap's total variation as the pinned signed-measure norm `(P.toSignedMeasure − Q.toSignedMeasure).totalVariation Set.univ` and record, citing `Jordan.lean` lines 91 and 141 in the Tau Ceti supplier contract, that it is `2 ⨆_A (P A − Q A)` for probability measures; keep the eventwise and sup forms as the owned statements. (4) Delete the two Mathlib pull-request references (lines 56–57; see R03). The worked examples then read as values of the signed-measure norm (2/3, 4/9, 0, 13/8 are unchanged under that convention). ## R02 (P2) — The exact-collision bound `1 − (n)_m/n^m` is attributed to Exchangeability Layer 8, which states only `choose m 2 / n`

**Location.** README lines 4–6 ("The completed Exchangeability roadmap (Layer 8) bounded the difference of the two laws on every event by the collision probability `1 − (n)_m / n^m`"), line 22–23 ("Exchangeability Layer 8 owns … the collision bounds"), L1.4 lines 68–72 (attaining `ExchangeableAt.etvDist_prefixLaw_sampleWithReplacement_le_exact_collision`), L4.1 line 106 ("Integrate the collision bound off `S`").

**Claim.** The exact-collision eventwise bound for sampling and for finite de Finetti is supplied by Exchangeability Layer 8, and L1.4 and L4.1 consume it.

**Witness.** `Completed/Exchangeability/README.md` lines 956–967 state the Layer 8 bound as `(m.choose 2 : ℝ≥0∞) / n` in both directions and nothing sharper. At the pinned Tau Ceti, `FiniteDeFinetti.lean` line 207 `ExchangeableAt.finiteDeFinetti` has error `m.choose 2 / n` (lines 215, 237, 250), and `UniformSampling.lean` line 177 `uniformOn_not_injective_le` is an inequality `≤ choose/n`; no declaration at the pin computes `uniformOn univ {¬injective}` as `1 − (n)_m/n^m`, and the name `ExchangeableAt.etvDist_prefixLaw_sampleWithReplacement_le_exact_collision` occurs nowhere at the pin (the gate's `readme-ids-missing` and the worker's citation check agree). The exact-collision sharpening is recorded only in `Completed/Exchangeability/PROGRESS.md` line 56 as later library work (TauCeti#18417, under the names `finiteDeFinetti_exact_collision` and `etvDist_prefixLaw_sampleWithReplacement_le`, neither of which is the name the README cites). A completed roadmap's README and the pin are what may be consumed; L4.1's route therefore uses an input that no layer, no supplier section and no pinned declaration provides, and L1.4 claims to attain a statement that does not exist where it is cited. With `S = ∅`, L4.1 *is* the exact-collision bound for random populations, so the roadmap already proves it implicitly while citing it as an input.

**What the pin does have.** `UniformSampling.lean` line 257 `uniformOn_injective_le_add` and line 272 `uniformOn_univ_le_injective_add`: eventwise comparison of uniform-on-injective and uniform-on-all with error `uniformOn univ {k | ¬ Injective k}` (uncomputed); `SamplingWithoutReplacement.lean` line 104 `ExchangeableAt.sampleWithoutReplacement_eq_prefixLaw` (exists at the pin; see R03 for how to present it); `FiniteDeFinetti.lean` line 123 shows how the eventwise bound integrates over a population law.

**Repair.** Own the exact-collision bound in L1 (it is three short targets): (a) for `Nonempty κ` (equivalently for `e : ι ↪ κ`, or for `m ≤ n` with `0 < n`), `uniformOn (univ : Set (ι → κ)) {k | ¬ Injective k} = 1 − p` — this is L1.2 for `x = id`, so state L1.2 in that form and derive the `Q x` version by pushforward; the hypothesis is needed: for `κ` empty and `m ≥ 1` the left side is `0` and the right side `1 − 0/0 = 1`; (b) for a probability law `ρ` and `e : ι ↪ κ`, every measurable `A` satisfies `sampleWithoutReplacement ρ A ≤ sampleWithReplacement ρ A + (1 − p)` and conversely, by integrating the pinned `uniformOn_injective_le_add` / `uniformOn_univ_le_injective_add` exactly as `sampleWithoutReplacement_le_sampleWithReplacement_add` does at the pin; (c) the same for `prefixLaw μ X m` against `sampleWithReplacement (prefixLaw μ X n)` via the pinned `sampleWithoutReplacement_eq_prefixLaw`. Then L1.4 attains target (c) with equality (its two mass identities already say so), L4.1 integrates target (b) off `S`, and lines 4–6 say that Layer 8 bounded the discrepancy by `choose m 2 / n`. Tested: with `n = 3, m = 2, ρ = δ_x`, target (b) gives error `1/3`, attained by `A = {injective words}` for injective `x` (table row 4).
