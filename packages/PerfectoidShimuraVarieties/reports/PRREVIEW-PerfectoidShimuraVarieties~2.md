## R01 (P3) — A "computation below" that the README does not contain, and the Δ_n(N) → Δ(N) injection fails at odd p too

Location: `TauCetiRoadmap/PerfectoidShimuraVarieties/README.md` line 1881 (Layer 5 Examples: "The `Q(√5), N=4, p=7` computation below rules out injectivity of every finite `Δ_n(N)` into `Δ(N)`") and line 1787 (§5.7: "for `p = 2` the transition maps … need not be injective … (BHW's proof of Lemma 8.20 assumes an injection `Δ_n(N) → Δ(N)` that need not exist)").

Claim: a ℚ(√5), N = 4, p = 7 computation exists in the README and shows that BHW's injection fails; the parenthetical places that failure under `p = 2`.

Witness: the only `p = 7` in the README is the GSp central-kernel remark of §0.3 (line 251); no Hilbert computation with `p = 7` appears anywhere. The failure is real and occurs at the odd prime 7: with `ε = (1+√5)/2`, `ε` has order 6 in `(𝒪_F/4)^×` and order 16 in `𝔽₄₉^×` (`ε^8 = ε·ε̄ = N(ε) = −1`), so `v = ε^{24}` satisfies `v ≡ 1 mod 4` and `v ≡ −1 mod 7`; `η = v² = ε^{48}` is trivial in `Δ(4) = 𝒪_F^{×,+}/((1+4𝒪_F)^×)²` but nontrivial in `Δ₁(4) = (1+7𝒪_F)^{×,+}/((1+28𝒪_F)^×)²`, since its only square roots `±ε^{24}` satisfy `ε^{24} ≡ −1 mod 7` and `−ε^{24} ≡ −1 mod 4`. BHW's proof of Lemma 8.20 (bhw line 1804–1806, p. 37) asserts this map "natural injective". The README's own odd-`p` argument (transition maps `Δ_{n+1}(N) → Δ_n(N)` injective: `η = 1 + pⁿx`, `η² ≡ 1 mod p^{n+1}` gives `2x ≡ 0 mod p`; orders bounded by `|(𝒪_F/N)^×|·2^{g+1}`) does not use BHW's injection, so §5.7's conclusions stand.

Repair: add the computation above as a Check of §5.7 ("for `F = ℚ(√5)`, `N = 4`, `p = 7`, `n = 1`, the class of `ε^{48}` is nontrivial in `Δ₁(4)` and trivial in `Δ(4)`"), and reword the parenthetical so that it does not tie BHW's unjustified injection to `p = 2`: "BHW's proof of Lemma 8.20 assumes an injection `Δ_n(N) → Δ(N)`, which fails already for `p = 7` (Check); for odd `p` stabilisation follows instead from the injective transition maps and the bounded orders, for `p = 2` only the kernel description holds".
