   **Claim.** The scalar-direction relation saving reduces to the rank-one pairing ⟨o_1, ψ′⟩ = 0, which is a computation in the completed group rings of class field theory.

   **Witness.** In rank one P_1 = O⟦G_loc × ℤ₂^{h¹}⟧ ↠ R^T_1 = O⟦Γ × ℤ₂^{2#T−1}⟧ is induced by a surjection of pro-2 abelian groups with kernel K, so J_1/m_P J_1 ≅ K/K² ⊗ k and the number of relations is d(K) = rank K + d(K_tors) = (h² − 1) + d(K_tors) (rank K = (#T + d) + h¹ − (d + 2#T − 1) = h¹ − #T + 1 and h¹ − h² = #T − 2 from h³ = 1). The adjoint of o_1 is injective (CHT08 Lemma 2.2.11, line 1029), so d(K) ≤ h² and K_tors is cyclic; ⟨o_1, ψ′⟩ = 0 means the image lies in ψ′^⊥, i.e. d(K) ≤ h² − 1, i.e. K_tors = 0: no nontrivial tuple of local 2-power roots of unity (ζ_v)_{v∈T} ∈ ∏_{v∈T} µ_{2^∞}(F_ṽ) has trivial image ∏_v Art_ṽ(ζ_v) in Γ. That is a global condition (for a quadratic dihedral η_α with α a T-unit of F⁺, η_α(∏_{v∈T} Art_ṽ(−1)) = (−1)^{#(real embeddings with α < 0)} by Hilbert reciprocity, so the diagonal −1 is excluded only when such an α with an odd number of negative embeddings exists), and the design neither states it nor verifies it.
