1. **F01** (P2) 3.1 API: I ∩ P is not every idempotent map with induced structure

   **Location.** `packages/AnalyticStacks/README.md` line 658, first API bullet of 3.1: "I ∩ P consists of the equivalences composed with idempotent maps with induced structure, all monomorphisms, so the decomposition (I, P) is suitable in the sense of 0.5."

   **Claim.** A map AnSpec B → AnSpec A lies in I ∩ P exactly when B is an idempotent A-algebra with the induced structure.

   **Witness.** ℤ_■ → ℤ_(p,■) is in P with ℤ_p idempotent (3.1 Check 2, line 665, which calls it a closed immersion), but it is not in I: a map in I ∩ P is at once an open immersion (j_♮ fully faithful) and, its right adjoint being the forgetful functor of Mod_B(D(A)), a closed immersion (in an adjoint triple j_♮ ⊣ j* ⊣ j_*, j_♮ is fully faithful iff j_* is), so the sublocale Sm(D(B)) ⊆ Sm(D(A)) is open and closed, 1 ≅ B × B′ with complementary idempotents (2.5, third API bullet), and B is a retract of A. ℤ_p is no retract of ℤ in D(ℤ_■): RHom_(ℤ_■)(ℤ_p, ℤ) = ℤ[1/p][−1] (dualise 0 → ℤ[[T]] →(T−p) ℤ[[T]] → ℤ_p → 0 against ℤ, with ℤ[[T]]^∨ = ⊕_ℕ ℤ and the transpose of T − p the backward shift minus p: kernel 0, cokernel colim(ℤ →p ℤ →p …) = ℤ[1/p]), so Hom(ℤ_p, ℤ) = 0. RCSolid itself only states that I is (−1)-truncated (Lemma 6.3.3(3), RCSolid line 4037; Remark 6.3.1, RCSolid line 4021) and never characterises I ∩ P. The inclusion I ∩ P ⊆ {idempotent induced maps} is right (the triple-adjunction argument gives B ⊗_A B ≅ B); the converse is what fails.

   **Repair.** Replace the bullet by: "I ∩ P consists of the maps A → B with B a dualizable idempotent A-algebra carrying the induced structure, that is A ≅ B × B′ with B, B′ the complementary idempotents of 2.5, equivalently the maps that are both open and closed immersions; every morphism of I is a monomorphism (RCSolid Lemma 6.3.3(3), RCSolid line 4037), so (I, P) is suitable in the sense of 0.5." Add the negative Check to 3.1: "ℤ_■ → ℤ_(p,■) is in P and ℤ_p is idempotent, but it is not in I: a map in I ∩ P makes B a retract of A, and Hom_(ℤ_■)(ℤ_p, ℤ) = 0 (RHom = ℤ[1/p][−1]); only ℤ_■ → ℤ_■ × ℤ_■ → ℤ_■ and its like lie in I ∩ P." Tested on the refuting instance: the projection ℤ_■ × ℤ_■ → ℤ_■ has induced structure, ℤ ⊕ ℤ ≅ ℤ × ℤ with complementary idempotents, and is open and closed; ℤ_■ → ℤ_(p,■) fails the retract condition. The only consumer of the bullet is 0.5's truncatedness hypothesis, which the monomorphism clause still supplies, so 3.2 and 3.3 are unaffected.

5. **F05** (P3) 1.7 second Check: the weight-one clause reads as the opposite of the heart condition

   **Location.** `packages/AnalyticStacks/README.md` line 461: "a static object in weight 1 is in the heart only after the shear places it in homological degree 1, i.e. it corresponds to M₁[1]".

   **Claim.** The Check pins the Beilinson heart on a weight-one object.

   **Witness.** By the shearing of 1.7 (M_n ↦ M_n[n]) the heart consists of the graded objects with every M_n[n] static. For M concentrated in weight 1: if M₁ = N is static then M₁[1] = N[1] is not static, so N placed in weight 1 is not in the heart; the weight-one objects of the heart are the M₁ = N[−1] with N static. Read literally the sentence says the static object "is in the heart" after shearing to degree 1, which is false; the intended statement (N is the sheared piece M₁[1], so M₁ = N[−1]) is recoverable only from the last clause. A wrong model (shear by M_n ↦ M_n[−n]) gets the opposite sign and the Check as worded does not separate the two.

   **Repair.** "a static N in weight 1 is in the heart only as the sheared piece: the heart's weight-one objects are the M₁ with M₁[1] static, i.e. M₁ = N[−1]; N itself in weight 1 is not in the heart, and the opposite shear M_n ↦ M_n[−n] would put N[1] there instead." Tested on N = ℤ, V = D(ℚ): M₁ = ℚ[−1] gives M₁[1] = ℚ static; M₁ = ℚ gives ℚ[1], not static.
