## R02 (P2) — The stated Euler-product tail cannot certify the root-balanced density 0.5501, so the constant 88497/100000 is unproved by the route

**Location:** `TauCetiRoadmap/ArithmeticStatisticsPartVI/README.md:2192`, “Prove P>0 and the tail estimate 0≤1−∏_(p>L,p≡3 mod 4)a_p≤Σ_(n>L)n⁻²≤1/L … giving density(F₃)>966888/1000000”; `README.md:2194`, “density(F⁺∪F⁻)>137525535061/250000000000”; consumers `README.md:2209`, `:2226`, `:2243` and `Suggested.lean:194`.

With the stated tail at `L = 10⁴` the certified bound is `F₃ ≥ 0.966797`; even `L = 10⁶` gives `0.966887 < 0.966888`. **Repair:** Replace the `n⁻²` tail by an explicit prime tail, for instance `Σ_{p>L} p⁻² ≤ c/(L log L)` from an explicit Chebyshev bound (Mathlib's `Chebyshev.eventually_primeCounting_le` is only eventual; state the explicit constant you use), restricted to `p ≡ 3 (mod 4)` if needed, and state the cutoff `L` (about `3·10⁴` with `c = 1.26·(1 + 1/log L)`) that certifies `F₃ > 0.966888`; add a Check recording that the `1/L` tail at `L = 10⁴` yields only `0.96680` and `μ ≥ 0.55005`.
