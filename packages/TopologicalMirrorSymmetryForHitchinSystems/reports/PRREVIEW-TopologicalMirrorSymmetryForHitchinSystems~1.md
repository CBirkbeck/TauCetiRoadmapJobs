## R01 (P2) — The parity hypothesis (n−1)·deg D even narrows §4.2 and §4.3 below the source and below the truth

**Location.** README Conventions (line 24: "The SL degree comparisons of §§4.2–4.3 additionally assume that (n−1)deg D is even"), §4.2 (lines 874–878, 884) and §4.3 (line 890, "when moreover (n−1)deg D is even").

**Claim.** The hypothesis is needed only by the route's choice N = M⁻¹Q^n with n·deg Q = deg M. GWZ20 Theorem 7.16 and Corollary 7.17 state the comparison without it, and it holds without it: for n even every e prime to n is odd, so a different N works.

**Witness.** Let n be even, choose T ∈ Pic(X)(k) with deg T = −(n−1)·deg D (a rational point of a Picard degree component exists over a finite field, as §4.2 already uses for Q), and put N = T^(n/2)·M⁻¹. Then deg N = −(n/2)(n−1)deg D + n(n−1)deg D/2 = 0, and by §3.10, (P^L)^e ≃ P^(L^e M^(1−e)) ≃ P^(L^e M^(1−e) ⊗ (T^((e−1)/2))^n) = P^(L^e N^(e−1)), because e−1 is even. The rest of the §4.2 route is unchanged. Instance: n = 2, deg D = 1, d = 1: deg M = −1, no Q with 2·deg Q = −1 exists (the README's own Check), but T = D⁻¹ gives N = TM⁻¹ = O and the comparison #M_SL^L = #M_SL^(L^e) for odd e holds (it is even the tensor identification of §3.5, since L^e = L ⊗ (L^((e−1)/2))²). Instance n = 4, deg D = 1, d = 1, e = 3: deg M = −6, deg T = −3, N = T²M⁻¹ of degree 0, and L³N² = L³M⁻² ⊗ T⁴ with T⁴ an nth power; this case is excluded by the README's hypothesis although the source's theorem covers it.

**Repair.** In §4.2 state: for n odd take Q with n·deg Q = deg M and N = M⁻¹Q^n; for n even take T with deg T = −(n−1)deg D and N = T^(n/2)M⁻¹; in both cases (P^L)^e ≃ P^(L^e N^(e−1)) because e−1 is even when n is even. Delete the parity clause from the Conventions paragraph, from §4.2's statement and from §4.3's SL clause. Replace the Check at line 884 by: at n = 2 and deg D = 1 no integral-degree Q satisfies 2·deg Q = −1, so the odd-n choice is unavailable, while T of degree −1 gives N = TM⁻¹; at n = 3 and deg D = 1 the odd-n choice deg Q = −1 works. Recompute the n = 2, g = 2, D = ω Check with the even-n formula: deg T = −2, N = T·ω has degree 0. Tested on the refuting instances above.

## R05 (P3) — §2.1's "admissible" differs from GWZ20 Definition 4.10 in both directions without saying so

**Location.** README §2.1, line 484: "Admissible means a presentation [U/Γ] with U smooth separated finite type, … a dense free locus whose complement in U has codimension at least two …" with locator "GWZ20 Definition 4.10".

**Claim.** Definition 4.10 (arXiv v3 lines 1164–1167) asks for U smooth quasi-projective with a generically fixed-point-free action and says nothing about codimension two; the codimension-two condition is Definition 6.8(c) on the torsor locus M′, and quasi-projectivity is what makes the coarse quotient U/Γ a scheme on which the orbifold measure of the generic orbifold contract is integrated. The README's notion is stronger in one clause (codimension two) and weaker in another (separated finite type, no affine-orbit condition, so U/Γ is only an algebraic space).

**Witness.** README §0.1 (line 192) imposes "every orbit lies in an affine open" for good actions; §2.1 does not, so the two admissibility notions of the same README disagree on a separated non-quasi-projective U with a non-good action, whose coarse quotient is not a scheme.

**Repair.** In §2.1 state the presentation as in Definition 4.10 (U smooth quasi-projective, or at least a good action so that U/Γ is a scheme), keep the codimension-two clause but attribute it to Definition 6.8(c), and note that §3.1 supplies quasi-projectivity of M_SL^L in the projective-curve setting used by §4.7.

## Source issues

- **Gap** in GWZ20 at Definition 2.16(c), §2.5, p.525: the source says two compatible root systems of q differ by a Galois automorphism, so the point-count relation is independent of the system; this holds for q prime, but for q = 4 the systems with s₂ = 2 and s₂ = −2 are not conjugate (2 ∈ ℚ); affects the proof (Theorems 2.18–2.19 for prime powers; repaired by transporting at prime residue fields, which suffice by Chebotarev, as the README does).
- **Misprint** in GWZ20 at Lemma 2.17 and the proofs of Theorems 2.18 and 6.12, pp.525–527, 569: the source says the roots of ℚℓ(1) have geometric Frobenius traces forming a system of roots of q and twists by (α), (F); with geometric Frobenius these should be ℚℓ(−1), (−α), (−F); affects nothing (a consistent sign convention).
