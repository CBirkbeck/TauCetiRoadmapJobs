   **Location.** packages/AutomorphicCongruences/README.md:1742, §5.3 Checks: "the composite with φ_(κ0), W ↦ w(κ0), gives w(κ0)·β(T), which vanishes exactly when f_(κ0) sits at W = 0."

   **Claim.** β(W·T) = 0 if and only if w(κ0) = 0.

   **Witness.** The second ring map inside β sends the cyclotomic variable γ⁺ to the central point c ∈ A^×, so T = γ⁺ − c has β(T) = 0 and β(W·T) = w(κ0)·0 = 0 at every weight point, including w(κ0) = 1 where f_(κ0) is not at W = 0. The "only if" direction fails.
