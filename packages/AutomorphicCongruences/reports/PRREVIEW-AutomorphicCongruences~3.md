**Why the reply's reason does not settle it.** The reply says the repair job may only retire a plan entry whose request the README owns or imports from the named supplier, and that adding entries is outside the job. Whether the roadmap repository's pull request or a board edit carries the change is a process question for the operator; the mismatch between what the intake reads and what the README requests is a defect of the declared contracts either way, and it is the only thing left to do.
