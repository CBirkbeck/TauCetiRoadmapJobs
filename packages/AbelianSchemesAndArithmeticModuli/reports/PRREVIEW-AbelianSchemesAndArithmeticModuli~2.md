## R01 (P3) — Module docstring omits A1.3 and misstates the differentials gap

**Location.** `TauCetiRoadmap/AbelianSchemesAndArithmeticModuli/Suggested.lean` lines 14–19 (the list of what the file covers) and lines 44–46 ("...the Hodge-line conclusions (A6) additionally need ... relative differential bundles").

**Claim.** The headline table (README line 32) lists `relativeInvariantForms` (A1.3: `π_*Ω¹_{A/S} ≅ ω_A`, `Ω¹_{A/S} ≅ π^*ω_A`, `ω_A` locally free of rank `g`). It is neither stated nor named in the docstring as not statable, and the docstring's only sentence about differentials says relative differential bundles are absent.

**Witness.** Tau Ceti at the pin has `AlgebraicGeometry.Scheme.relativeDifferentials R X` for a scheme `X` over `Spec R`, `R` a commutative ring (`TauCeti/AlgebraicGeometry/Modules/Differentials/Basic.lean` line 85), with `FiniteLocallyFreeSheaf.relativeDifferentials` under `Smooth (X ↘ Spec (.of R))` (`TauCeti/AlgebraicGeometry/Modules/Differentials/LocallyFree.lean` line 95) and `InvertibleSheaf.relativeDifferentials` in relative dimension one (`TauCeti/AlgebraicGeometry/Modules/Differentials/Rank.lean` line 112). What is absent is the sheaf over a general base scheme `S`, which A1.3 and A6.38 need; over an affine base the A1.3 statement is expressible.

**Repair.** In the docstring, name A1.3 and A6.38 among the headlines not stated and give the exact gap: Tau Ceti's relative differentials exist only over an affine base `Spec R`, not over a general base scheme, so `ω_A`, `Ω¹_{A/S} ≅ π^*ω_A` and `det ω_A` cannot be stated for an arbitrary `S`. Alternatively state the affine-base instance of A1.3 on `Scheme.relativeDifferentials R` with `SmoothOfRelativeDimension g`; the author's call.

## R03 (P3) — Redundant unit hypothesis in `rosatiPositiveSquareRoot`

**Location.** README A6.15, line 3027: "For a positive self-adjoint unit `s`, prove `rosatiPositiveSquareRoot`".

**Witness.** Positivity already gives invertibility: `IsRosatiPositive t s` makes `L_s` positive definite for the inner product `⟨x, y⟩ = t(x y^†)` (`⟨L_s x, x⟩ = t(s x x^†) > 0`), so `L_s` is injective on the finite-dimensional `E`, hence bijective, so `s` has a left inverse `L_s^{-1}(1)` and, by finite dimension, a two-sided inverse. The README's own proof (line 3033, "Invertibility follows from the positive spectrum") derives the unit property rather than using it.

**Repair.** Delete "unit" from the hypothesis (keep the conclusion "it is a unit"), so the statement matches the proof and A6.24's use, which applies it to `s = f^†f` without first proving `s` is a unit.
