## R01 (P3) — The field Check of A1.7 asserts finiteness of `A[n]` for every `n`, including `n = 0`

**Location.** `README.md:938–940`: "Over a field the statement has no content: `A[n]` is a finite `K`-scheme, the spectrum of a semilocal ring, so `Pic(A[n])` is trivial."

**Claim.** The Check quantifies over the same `n` as the paragraph above it, which states the target "for every integer `n`" and records "`A[0] = A` with exponent `0`" (`README.md:922, 933`). For `n = 0` the kernel is `A` itself, not a finite `K`-scheme, and `Pic(A)` is not trivial for `g ≥ 1`.

**Witness.** `A = E` an elliptic curve over `K`, `n = 0`: `mulBy 0 = 𝟙 ^ 0 = 1`, the zero endomorphism `e ∘ π`; the pullback of `e ∘ π` along `e` is `{(a, s) : π(a) = s} ≅ E`, and `Pic(E) ⊇ E(K)` is nontrivial. The target itself is unaffected: the exponent `2 · 0² = 0` makes all three clauses `m ^ 0 = 1`, as the paragraph says.

**Repair.** Begin the Check with the restriction the reason needs: "Over a field and for `n ≠ 0` the statement has no content: `A[n]` is a finite `K`-scheme …", keeping the rest. For `n = 0` the paragraph's own remark (exponent `0`) already covers the field case.
