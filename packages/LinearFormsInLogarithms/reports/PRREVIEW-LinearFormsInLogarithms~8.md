## R01 (P3) — `e` in “for `e < (p − 1) i`” is undefined here and clashes with the roadmap's `e`

**Location.** `TauCetiRoadmap/LinearFormsInLogarithms/README.md` line 50: “`TauCeti.deepUnitExpLogEquiv`, for `e < (p − 1) i`, is the isomorphism of topological groups”.

**Claim.** The sentence states the threshold of the cited declaration with a symbol `e` that this README never introduces as the absolute ramification index of `K`. In this README `e` is Euler's number: line 95 (“It does not prove that `e` or `π` …”), line 97, line 117 (“the worked examples for `e` and `π`”), line 951 (“Hence `e` and `π` are transcendental (`transcendental_e`, …)”). The nearest reader-visible definition of this `e` is in another roadmap (Completed/LocalFieldsRamification README line 394, “`e = absoluteRamificationIndex K p`”), which the sentence does not point at. Read with the roadmap's own `e`, the condition is meaningless; the house rule is that every symbol is standard or defined where it first appears, and here the standard meaning is overridden by the document's own.

**Witness.** The pinned declaration is `TauCeti.deepUnitExpLogEquiv (hi : absoluteRamificationIndex K p < (p - 1) * i)` at `TauCeti/NumberTheory/LocalField/DeepUnits/Basic.lean` line 117, with `K` a `FinitePadicExtension K p`. Its hypothesis names `absoluteRamificationIndex K p`, not a free `e`; nothing in the changed passage or the rest of the README binds `e` to it.

**Repair.** Say what `e` and `i` are in the sentence, and keep the exponential on its actual domain: “`TauCeti.deepUnitExpLogEquiv`, for a depth `i` with `e < (p − 1) i` where `e` is the absolute ramification index of `K` over `ℚ_p`, is the isomorphism of topological groups `U(K,i) ≃ₜ* Multiplicative (𝓂[K] ^ i)` given by the logarithm on the deep units `U(K,i) = 1 + 𝓂[K]^i`, with the exponential on `𝓂[K]^i` as its inverse.” Tested on the instance: `K = ℚ_3`, `e = 1`, `i = 1` satisfies `1 < 2`; `K = ℚ_2`, `e = 1`, `i = 1` fails `1 < 1` and `i = 2` satisfies `1 < 2`, which is exactly the Tau Ceti hypothesis and agrees with 8.1's radius (`2` is on the boundary at `p = 2`). With `e` read as Euler's number, `2.718… < (3 − 1) · 1` is false at `p = 3, i = 1`, where the declaration does apply: the ambiguity changes the truth value.
