## R02 (P3) — `noLowWeightKTheory_numberField` for every number field cites an injectivity that L3.Fc.1 states only for `k/ℚ` Galois

**Location.** `README.md` line 2416 ("a number field `k`, and more generally a subfield of `ℚ̄` … follows from the injectivity of the complex regulator `(Φ_∞ ∘ σ)_σ` proved in L3.Fc.1") and the *Needs:* line 2419 ("L3.Fc.1 (the injectivity of `(Φ_∞ ∘ σ)_σ` on `K_(2n−1)(k)_ℚ`…)"); L3.Fc.1 line 2655 ("Let `n ≥ 2, k/ℚ` be finite Galois with group `G` … the map `(Φ_∞ ∘ σ)_σ` is injective on `K_(2n−1)(k)_ℚ`").

**Claim.** For every number field `k`, injectivity of the regulator on `K_(2n−1)(k)_ℚ` is available from L3.Fc.1.

**Witness.** L3.Fc.1's standing hypotheses make `k/ℚ` Galois, so the regulator theorem as stated does not cover `k = ℚ(2^(1/3))` (`r₁ = r₂ = 1`, `dim K_3(k)_ℚ = 1`), while `noLowWeightKTheory_numberField` is stated for it; a subfield of `ℚ̄` that is not Galois over `ℚ` is not a filtered union of Galois number fields either (its only Galois subfield may be `ℚ`), so the filtered-union clause does not bridge the gap. The source needs no Galois hypothesis: BBdJR line 216 (Theorem 2.2, p. 5) is for a number field `k` of degree `d`. The mathematics is right; only the route's scope is short by one step.

**Repair.** Either (a) in L3.Fc.1 state the regulator theorem (injectivity and lattice image) for every number field `k`, as BBdJR Theorem 2.2 does, keeping the Galois hypothesis only for the `G`-action, `M^E_π` and the pairings; or (b) in L3.Fa.1's bullet add the transfer step: for the Galois closure `k'/k`, the composite of `K_(2n−1)(k) → K_(2n−1)(k')` with the transfer is multiplication by `[k' : k]`, so the map is injective rationally, and it commutes with every `ψ^a`, so `K^(j)_(2n−1)(k)_ℚ` embeds in `K^(j)_(2n−1)(k')_ℚ = 0` for `j ≠ n`. Tested on the instance: with (b), `k = ℚ(2^(1/3))`, `k' = ℚ(2^(1/3), ζ_3)` (`r₂ = 3`, `dim K_3(k')_ℚ = 3`), the weight-`j ≠ 2` part of `K_3(k)_ℚ` injects into the weight-`j` part of `K_3(k')_ℚ`, which the Galois case kills.
