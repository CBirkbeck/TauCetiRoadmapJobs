1. **F01** (P3) §1.6's first Check uses an instance that does not exhibit the failure

   **Location.** README line 411 (§1.6 Checks): "For 𝔤₁ = 𝔤, a proper 𝔤₂ and b = 1 on 𝔤₂^∧, the pull-back of b to 𝔤^∧ is constant along the annihilator of 𝔤₂ and has no decay there; the product is a symbol only if a decays in those directions".

   **Claim.** The instance shows why a proper 𝔤₂ forces `m₁ = −∞`.

   **Witness.** For b = 1 the pull-back is the constant 1 ∈ `S^0(𝔤^∧)`, and `a ⋆⁰ b = a` is a symbol for every `a ∈ S^m`, decaying or not: the "only if" fails on this instance. nv21 Example 7.1, p. 47, takes the opposite data: a constant a and a compactly supported b on `𝔤₂^∧`. Computed: for such b and `ζ = ζ₀ + ζ′` with `ζ′ ∈ 𝔤₂^⊥ → ∞` and `∂^α b(ζ₀|_{𝔤₂}) = c ≠ 0`, `∂^α(a ⋆⁰ b)(ζ) = c` for all ζ′ while `⟨ζ⟩^{m−|α|} → 0` once `|α| > m`, so `a ⋆⁰ b` lies in no `S^m`; for Schwartz a the product `a(ζ) b(ζ|_{𝔤₂})` is Schwartz.

   **Repair.** At line 411 replace "b = 1 on 𝔤₂^∧" by "b a compactly supported bump on 𝔤₂^∧ and a = 1", and the clause after the semicolon by "a ζ-derivative of order above m of the pull-back is a nonzero constant along a line of the annihilator while `⟨ζ⟩^{m−|α|} → 0`, so the product lies in no `S^m` unless a decays in those directions, which is why a proper 𝔤₂ forces a to be Schwartz (NV21 Example 7.1, p. 47)". Tested on the refuting instance: with a = 1 and b a bump the product is not a symbol; with a Schwartz it is.

2. **F02** (P3) §1.4 states the centre count without its h-dependence

   **Location.** README line 377 (§1.4): "with overlap bounded independently of h, comparable weights `⟨ω⟩ ≍ ⟨ω′⟩` on intersecting balls and at most polynomially many centres in a ball of radius R".

   **Claim.** The number of centres of `Ω_{δ,h}` in a ball of radius R is polynomial in R.

   **Witness.** nv21 Lemma 7.11(ii), p. 51: `#{ω ∈ Ω : |ω| ≤ X} ≪ h^{−O(1)} X^{O(1)}`. Computed: for δ > 0 and n = dim 𝔤 ≥ 1, the balls `U_ω` near 0 have radius `≍ h^δ`, so covering the unit ball needs `≍ h^{−nδ}` centres, unbounded as h → 0; the README's own next Check (line 390) computes exactly this. Read as uniform in h, the sentence is false for δ > 0.

   **Repair.** At line 377 write "and at most `h^{−O(1)} R^{O(1)}` centres in a ball of radius R (polynomially many in R and in `h^{−1}`)". Tested: at δ = 0 the count is `≍ R^n`, h-free, as the Check at line 390 says; at δ > 0 it is `≍ h^{−nδ} R^n`.

3. **F03** (P3) §2.4's route writes the Nelson–Casimir identity with the wrong constant

   **Location.** README line 556 (§2.4 *Proof route*): "In a Cartan-compatible basis `Δ = 2Δ_K − C_𝔤 + 1` up to normalization".

   **Claim.** The identity relating Δ, the K-Laplacian and the Casimir.

   **Witness.** nv21 proof of Lemma 9.5, p. 78: `Δ = 2Δ_K − 1 − C` with `Δ_K = 1 − Σ y_i²` and `C = −Σ y_i² + Σ z_j²`. Computed: `2Δ_K − 1 − C = 2 − 2Σy² − 1 + Σy² − Σz² = 1 − Σy² − Σz² = Δ`, whereas `2Δ_K − C + 1 = Δ + 2`. "Up to normalization" covers the sign and scale of the Casimir, not an additive shift; the eigenvalue bound of (i) is unaffected.

   **Repair.** At line 556 write "`Δ = 2Δ_K − 1 − C_𝔤` with `Δ_K = 1 − Σ_{𝔨} x²` and `C_𝔤` the Casimir of the (possibly negated) Killing form". Tested on SU(2) with the orthonormal basis of §0.1: 𝔭 = 0, `Δ_K = Δ`, `C = −Σy² = Δ − 1`, and `2Δ − 1 − (Δ − 1) = Δ`.
