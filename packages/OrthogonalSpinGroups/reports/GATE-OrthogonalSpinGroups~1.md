## H01 (roed-math) — applied
§0B no longer carries the false "the same statements hold for `SO`" claim. At `108b007` it already separated the summand-preserving subgroup of total `SO` (`det g₁·det g₂ = 1`) from the image of `SO(Q₁)×SO(Q₂)` (`det g₁ = det g₂ = 1`). This round adds two things.

- The pinned Tau Ceti already proves this interface (`TauCeti/LinearAlgebra/QuadraticForm/Prod.lean`: `QuadraticMap.mem_range_orthogonalGroupProd_iff` l.251, `det_orthogonalGroupProd` l.277, `mem_range_specialOrthogonalGroupProd_iff` l.326). §0B now consumes these declarations instead of restating them, and they are listed under "What Tau Ceti already has".
- §0B has three Checks: `⟨1⟩ ⊞ ⟨1⟩` over ℚ with `−I₂`; the same forms under `O`, where the swap shows the embedding is not onto; and a zero summand. It also states that the index is 2 when both summands are nondegenerate of positive dimension, because `(τ₁, τ₂)` lies outside the `SO×SO` image.

## H02 (roed-math) — applied
§3G already requires `Φ(ΔG(ℚ)) = ΔG'(ℚ)` alongside `Φ(U) = U'` (at `108b007`). It states the representative rule `[g] ↦ [Φ g]` with its inverse from `Φ.symm`, and proves the diagonal condition for the specialization induced by one rational isometry. The counterexample was recomputed:
- `Q = a² + ab + 6b²` has discriminant −23.
- `N(ω − 2) = 4 − 2 + 6 = 8`.
- Norm 2 is impossible because `8 = (2a+b)² + 23b²` forces `b = 0` and then `(2a)² = 8`.

So `[P]` has order 3. The pinned Tau Ceti has no double-coset API (`NumberTheory/QuadraticForm/OrthogonalGroup/` has no `DoubleCoset`), so §3G remains a target.

## H03 (roed-math) — applied
The standing conventions (README l.166–170) and §1A (l.493–497) now say that `[Q v]` and `[−Q v]` differ exactly when `[−1]` is nontrivial. Over `ℚ_p` that happens for `p = 2` and for odd `p ≡ 3 (mod 4)`. Checked values:
- `2² = 4 ≡ −1 (mod 5)` lifts by Hensel's lemma, so `[−1]` is trivial in `ℚ_5`.
- `−1 ≡ 7 (mod 8)` is a nonsquare in `ℚ_2`.

## H04 (roed-math) — applied differently
At `108b007` the dimension-one acceptance test separated the two conditions, but it still called `Q x = x²` "the degenerate one [that] tests nothing". That contradicts the separation: over ℚ this instance gives `[1]` for the `reverse` norm and `[−1] ≠ [1]` for the `star` norm, so it is exactly the instance that discriminates between the conventions. The Check now says:
- "`a` nonsquare" tests that `reverse θ(−1) = [a]` is nontrivial.
- "`−1` nonsquare" separates the conventions, since `star` gives `[−a]`.
- `Q x = x²` over ℚ is the discriminating witness.
- Over `ℚ_5` no instance separates the two conventions.
