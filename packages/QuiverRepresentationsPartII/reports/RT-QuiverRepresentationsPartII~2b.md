1. **F01** (P3) `grid_path_chain_max` carries an unused hypothesis and an over-strict one

   **Location:** `packages/QuiverRepresentationsPartII/Suggested.lean:199`: “theorem grid_path_chain_max (m : Multisegment) {r a : ℕ} (ha : 1 ≤ a) (har : a < r) (hm : InWindow m r)”; `packages/QuiverRepresentationsPartII/README.md:550`: “for `InWindow m r` and `1≤a<r`, every grid path has weight at most Eₐ(m), and some path attains Eₐ(m)”.

   **Claim:** Attainment holds for every `a ≤ r` under `InWindow m r` alone; `ha : 1 ≤ a` is never used and `har : a < r` only excludes `a = r`, where the statement is still true (for `a > r` the structure `GridPath r a` is empty, so `a ≤ r` is the exact hypothesis). The argument of §4.6 (interpolate a maximum inclusion chain by unit steps and extend to the two corners) uses only that every cut interval `[i,j]` has `1 ≤ i ≤ a+1` and `a ≤ j ≤ r`, which `InWindow` and membership in the cut give for every `a ≤ r`. The source states the case `a ∈ [1, r−1]` because it is all the Knight–Zelevinsky rewriting needs (AKY p.19, line 793 of the cached copy); the boundary cases are not excluded by anything in the proof.

   **Witness:** `a = 0`, `r = 2`, `m = [1,1]`: `cutPart m 0 = {[1,1]}` (contains `a+1 = 1`), `E₀(m) = 1`; the path `(1,0),(1,1),(1,2)` has vertex weights `(0,1,0)`, total `1 = E₀(m)`. `a = r = 2`, `m = [1,2]`: `cutPart m 2 = {[1,2]}`, `E₂(m) = 1`; the path `(3,2),(2,2),(1,2)` has weights `(0,0,1)`, total `1`. In general at `a = 0` the cut is the nested family `{[1,j]}` and the all-up path visits every `[1,j]`, `1 ≤ j ≤ r`; at `a = r` the cut is the nested family `{[i,r]}` and the all-left path visits every `[i,r]`, `1 ≤ i ≤ r`; so the path weight is the whole cut cardinality `= Eₐ(m)`. The previous pass's weakening of `GridPath.weight_bound` (repair report, review b F04) left this companion statement with the same shape of surplus hypotheses.

   **Exact repair text:**
   ```lean
   /-- Some path realizes the weighted chain maximum; paths and chains need not be bijective. -/
   theorem grid_path_chain_max (m : Multisegment) {r a : ℕ}
       (har : a ≤ r) (hm : InWindow m r) :
       ∃ p : GridPath r a, p.weight m = chainWeight m a := by sorry
   ```
