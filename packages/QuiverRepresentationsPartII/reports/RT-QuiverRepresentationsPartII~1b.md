   **Claim:** The bound holds for every `r`, `a` and `m`. Every vertex `(i, j)` of a `GridPath r a` satisfies `i ≤ a + 1` and `j ≥ a` (the first coordinate only decreases from `a + 1`, the second only increases from `a`); a vertex with `i ≤ j` is therefore an interval meeting `{a, a + 1}` (if `i ≤ a` it contains `a`; if `i = a + 1 ≤ j` it contains `a + 1`), so it lies in the support of `cutPart m a` or has weight `0`; distinct vertices are distinct intervals, and along the path left endpoints decrease while right endpoints increase, so the valid vertices form an inclusion chain. Hence `p.weight m` is the weight of a chain counted by `chainWeight m a`, with no use of `InWindow`, `1 ≤ a` or `a < r`. Only `grid_path_chain_max` (existence of a path attaining the maximum) needs `InWindow m r` (for `m = [0,1]`, `a = 1`, `r = 3` the cut weight is `1` but no vertex has first coordinate `0`).
