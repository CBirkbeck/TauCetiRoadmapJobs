## R01 (P3) — `exists_representableBy_gammaNaive` carries an invertibility hypothesis the statement holds without

**Location.** `TauCetiRoadmap/ModularCurves/Suggested.lean` lines 905–909 (`(hN : ∀ b : B, (N : B.residueField b) ≠ 0) (h3 : 3 ≤ N) : ∃ X : EllObj B, Nonempty ((ModuliProblem.gammaNaive B N).RepresentableBy X) ∧ IsAffineHom X.structureMap ∧ Smooth X.structureMap`); `README.md` 5B lines 2197–2203 ("for every base `B` on which `N` is invertible … Over a general such `B` the representing object is the base change of `Y_full(N)/ℤ[1/N]`").

**Claim.** Neither the statement nor the route needs `hN`. For an arbitrary scheme `B` the object `Y_full(N) ×_{Spec ℤ} B` (with `Y_full(N) → Spec ℤ[1/N] → Spec ℤ`) represents `gammaNaive B N`: for `T → B` with a point of residue characteristic `p ∣ N` both sides are empty (no map `T → Spec ℤ[1/N]`; no injective `(ℤ/Nℤ)² → E[N](κ)`, since `E[p](κ̄)` has rank at most one), and for `T` on which `N` is invertible both sides are the naive structures on `E/T` by the representability over `ℤ[1/N]`. The structure map is the base change of `Y_full(N) → Spec ℤ[1/N] → Spec ℤ`, affine (affine over an affine open `D(N)` of `Spec ℤ`) and smooth. The pinned inputs the route uses carry no such hypothesis either: `isRigid_gammaNaive (3 ≤ N)` and `gammaNaiveRelRepData` are stated over every base (`NaiveLevel.lean`, elaborated types in the scratch transcript), and the naive locus is open and closed inside the finite étale `(E[N] ×_S E[N])|_{S[1/N]}`, so it is affine over `S` for every `S`.

**Witness.** Instance `B = Spec ℤ`, `N = 3`, where `hN` fails at the point `(3)`: `X = ⟨Spec ℤ[1/3, ζ₃][μ, 1/(μ³ − 1)] → Spec ℤ, universalLevelThree⟩` represents `gammaNaive (Spec ℤ) 3` by `gammaNaiveThreeRepresentableBy` (stated for every base `B`, `Rigidifier/LevelThree.lean` 259), and its structure map is affine and smooth. So the conclusion holds where the hypothesis fails, and the hypothesis is dead weight: stated with it, the theorem cannot be applied with `B = Spec ℤ`, although the representing object exists there (Layer 9D's rigidifiers `[Γ(3)]` on `D(3)` and `[Γ(4)]` on `D(2)` are its restrictions).

**Repair.** Delete `hN` from the signature, and in the docstring and README 5B replace "over a base `B` on which `N` is invertible" by "over every base `B`, the representing object being the base change of `Y_full(N)/ℤ[1/N]` along `B → Spec ℤ`, empty over the locus where `N` is not invertible". `#check @exists_representableBy_gammaNaive` after the change.
