- `Suggested.lean` line 699: `[F.IsComm]` in `formalGroup_p_eq_zero_of_pow_mem_span`. The proof uses only `F(X,Y) = X + Y + (degree ≥ 2)`: comparing total-degree-`pⁿ` terms of `F^{pⁿ} = X^{pⁿ}A + Y^{pⁿ}B` gives `(X+Y)^{pⁿ} = X^{pⁿ}A(0,0) + Y^{pⁿ}B(0,0)`, so `A(0,0) = B(0,0) = 1` and `C(pⁿ,i) = 0` for `0 < i < pⁿ`; commutativity is never used.
