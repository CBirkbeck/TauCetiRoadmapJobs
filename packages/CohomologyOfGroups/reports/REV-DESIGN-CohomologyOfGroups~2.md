1. **F01** (P1) An unbounded complex can have a globally bounded filtration

   **Location:** `packages/CohomologyOfGroups/design/README.md:1180`, especially line 1182: “but no `F_t` is zero when `C̄` is unbounded”; also `packages/CohomologyOfGroups/design/plan.json:1395`, target 6.1's boundedness API.

   **Claim:** Unboundedness of normalized cochains prevents every global lower bound for the filtration `F_t = A_{−t}`.

   **Witness:** `N=G=C₂`, `k=M=𝔽₂`, trivial action: `C̄ⁿ=𝔽₂` for every `n≥0`, but `F_{−1}=A₁=0`. The existing Check at README line 1195 already computes the latter.

   There is exactly one tuple of nonidentity elements in each degree, so the normalized cochain complex is unbounded. Since all arguments belong to `N`, the defining vanishing condition for `A₁` kills every positive-degree cochain; it also kills degree zero by the convention for `j > n`. This contradicts the new API assertion, not the corrected stabilization argument in 6.2.

   **Exact repair:** Replace the global impossibility clause in both files by: “The filtration is bounded in each degree; a global lower bound is not guaranteed.” Retain `F_t = C̄` for `t ≥ 0`. Strengthen the two existing boundary Checks: for `N = G = C₂`, `M = 𝔽₂`, the unbounded complex has `F_{−1} = 0`; for `N = 1`, `G = C₂`, `M = 𝔽₂`, every `F_t` is nonzero. Indeed, in the latter case `A_j` contains a nonzero cochain in every degree `n ≥ max(j,0)`. Both instances satisfy the replacement, and they distinguish a degreewise bound from a compulsory absence of global bounds. Keep the repaired 6.2 convergence route.
