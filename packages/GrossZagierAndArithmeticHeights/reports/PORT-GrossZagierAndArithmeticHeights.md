## Draft pull request body

This roadmap builds arithmetic height pairings and the local-to-global kernel comparisons behind Gross–Zagier formulas on modular and quaternionic Shimura curves. It develops CM level-point comparisons, admissible intersections, toric test vectors and normalized theta kernels, then relates weight-two anticyclotomic special values to squared logarithms with explicit periods, Euler factors and integral structures. These interfaces supply Heegner-point and arithmetic-rank applications.
