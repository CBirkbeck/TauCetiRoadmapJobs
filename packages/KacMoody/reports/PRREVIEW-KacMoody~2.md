## R01 (P3) — The `A_2` Chevalley–Pieri Check evaluates `wλ` for the wrong element and swaps the two coefficients

Location: `README.md` lines 1116–1119: "Type `A_2`, `w = s_1 s_2`, `λ = ω_1`, `wλ = −ω_2`: the boundary components are `X_(s_1)`, with `β = θ` and coefficient `|⟨−ω_2, θ^∨⟩| = 1`, and `X_(s_2)`, with `β = α_1` and coefficient `|⟨−ω_2, α_1^∨⟩| = 0`; … `X_(s_2)` is contracted to a point".

Claim: for `w = s_1 s_2` the divisor of `p_(wλ)` on `X_w` is `1·[X_(s_1)] + 0·[X_(s_2)]`.

Witness: `s_2 ω_1 = ω_1` (since `ω_1(h_2) = 0`), so `s_1 s_2 ω_1 = ω_1 − α_1 = ω_2 − ω_1`, not `−ω_2` (`−ω_2 = s_2 s_1 ω_1`). With the correct `wλ = ω_2 − ω_1`, the formula of 7.3 gives `|⟨ω_2 − ω_1, h_1⟩| = 1` on `X_(s_2)` (`β = α_1`) and `|⟨ω_2 − ω_1, h_1 + h_2⟩| = |−1 + 1| = 0` on `X_(s_1)` (`β = θ`): the opposite of the Check. The `γ` form agrees: `γ = −w⁻¹α_1 = θ`, `⟨ω_1, θ^∨⟩ = 1`; `γ = −w⁻¹θ = α_2`, `⟨ω_1, h_2⟩ = 0`. Geometrically `s_1` and `w` lie in the same coset of `W_λ = ⟨s_2⟩`, so `p_(wλ)` does not vanish on `X_(s_1)` (coefficient `0`), while `X_(s_2)` is the fibre over the base point `eP` of the orbit map `X_w → X_(s_1)P/P ≅ ℙ¹`, where the coordinate `p_(s_1 ω_1)` vanishes simply: the contracted component carries the coefficient `1`, not `0`. The theorem of 7.3 is right; the Check mis-evaluates it.

Repair (tested on the instance): write `wλ = ω_2 − ω_1`, "`X_(s_2)`, with `β = α_1`, coefficient `|⟨ω_2 − ω_1, h_1⟩| = 1`, the fibre contracted to the point `eP`; `X_(s_1)`, with `β = θ`, coefficient `|⟨ω_2 − ω_1, θ^∨⟩| = 0`, since `s_1 ω_1 = wλ`; the zero coefficient must be kept". Alternatively take the minimal representative `w = s_2 s_1`, `wλ = −ω_2`, where both coefficients are `1` (`|⟨−ω_2, h_2⟩|` on `X_(s_1)`, `|⟨−ω_2, h_1 + h_2⟩|` on `X_(s_2)`) and `X_(s_1)` is the exceptional curve of `X_w → ℙ²`, the blow-up of `ℙ²` at `eP`; I checked both.

## R02 (P3) — The negative control for the two-cut form is a monotone path

Location: `README.md` lines 891–892: "An integral global minimum alone is insufficient for the two-cut form: a path with heights `0, 1, 0, 1, 2` has `m = 0` but is not monotone between the cuts."

Claim: the two-cut hypothesis fails for this path.

Witness: with the cuts of 5.2 (and Lenart–Postnikov lines 922–924): `t_0` is the last minimum, the second `0` (time `1/2` at equal spacing); `t_1` is the first time after which `H ≥ m + 1 = 1`, the second `1` (time `3/4`). On `[1/2, 3/4]` the path is one linear segment from `0` to `1`, weakly increasing, so the hypothesis holds and the two-cut recipe and the record formula agree: both give `f π` with heights `0, 1, 0, −1, −2`.

Repair (tested): replace by heights `0, −1, −1/4, −1/2, 1` at times `0, 1/4, 1/2, 3/4, 1`: `m = −1` is integral, `t_0 = 1/4`, `t_1 = 5/6` (where `H` crosses `0` on the last segment), and on `[1/4, 5/6]` the height rises to `−1/4` and falls to `−1/2`, so the monotonicity fails while the record formula still applies. (The rational-minimum example `0, 6/5, 1/5, 1` of the first Check is not a substitute: it tests a non-integral minimum.)
