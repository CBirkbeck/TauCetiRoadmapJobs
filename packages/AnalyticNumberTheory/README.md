# Roadmap: analytic number theory

**Summary.** This index connects two owning roadmaps. [AnalyticNumberTheoryPartI, Layers 0–3](https://github.com/TauCetiProject/TauCetiRoadmap/blob/roadmap/analytic-number-theory-part-i/TauCetiRoadmap/AnalyticNumberTheoryPartI/README.md#how-to-read-the-build) develops quantitative prime estimates, explicit formulas, Hecke and Artin comparisons, multiplicative means, smooth numbers and zeta moments. [AnalyticNumberTheoryPartII, Layers 4–6](https://github.com/TauCetiProject/TauCetiRoadmap/blob/roadmap/analytic-number-theory-part-ii/TauCetiRoadmap/AnalyticNumberTheoryPartII/README.md#how-to-read-the-build) uses that arithmetic analysis for Lerch and Barnes functions, quadratic double and binary-cubic series, the Bost–Connes phase transition and compact scalar determinants.

## Scope and ownership

This file supplies navigation; every mathematical target belongs to one of the two parts. [Part I, Scope and ownership](https://github.com/TauCetiProject/TauCetiRoadmap/blob/roadmap/analytic-number-theory-part-i/TauCetiRoadmap/AnalyticNumberTheoryPartI/README.md#scope-and-ownership) specifies the boundary with the arithmetic and analytic suppliers. [Part II, Scope and ownership](https://github.com/TauCetiProject/TauCetiRoadmap/blob/roadmap/analytic-number-theory-part-ii/TauCetiRoadmap/AnalyticNumberTheoryPartII/README.md#scope-and-ownership) specifies the special-function, arithmetic-series and operator boundaries. Their READMEs contain the target statements, hypotheses, APIs, Checks and source locators; their [Part I signatures](https://github.com/TauCetiProject/TauCetiRoadmap/blob/roadmap/analytic-number-theory-part-i/TauCetiRoadmap/AnalyticNumberTheoryPartI/Suggested.lean) and [Part II signatures](https://github.com/TauCetiProject/TauCetiRoadmap/blob/roadmap/analytic-number-theory-part-ii/TauCetiRoadmap/AnalyticNumberTheoryPartII/Suggested.lean) state the headline theorems. This index adds no mathematical target or Lean declaration.

## Conventions

Each target uses its owner's conventions: [Part I, Conventions](https://github.com/TauCetiProject/TauCetiRoadmap/blob/roadmap/analytic-number-theory-part-i/TauCetiRoadmap/AnalyticNumberTheoryPartI/README.md#conventions) for Layers 0–3 and [Part II, Conventions](https://github.com/TauCetiProject/TauCetiRoadmap/blob/roadmap/analytic-number-theory-part-ii/TauCetiRoadmap/AnalyticNumberTheoryPartII/README.md#conventions) for Layers 4–6.
