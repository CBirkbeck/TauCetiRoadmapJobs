1. **F01** (P2) §1.1 identifies `e(f) = 1` with Mathlib's `Scheme.Birational`, a relation between schemes

   **Location.** `design/README.md` line 142 (§1.1, *Birationality*): "`e(f) = 1` if and only if `f^*` is an isomorphism, if and only if `f` is birational in the sense of Mathlib's `Scheme.Birational`". Also line 55 (From Mathlib: "`Birational` … are birational maps") and the uses of "birational `φ`" at lines 165, 197, 507, 570 with no definition of a birational rational map.

   **Claim.** The three conditions are equivalent.

   **Witness.** Mathlib at the pin, `Mathlib/AlgebraicGeometry/Birational/Birational.lean:181`: `def Birational (X Y : Scheme.{u}) : Prop := Nonempty (PartialIso X Y)`. It is a property of the pair `(X, Y)`, not of a map. Instance: `X = Y = ℙ¹_K`, `f(z) = z²`. `Scheme.Birational ℙ¹ ℙ¹` holds (the identity partial isomorphism), while `e(f) = [K(z) : K(z²)] = 2` and `f^*` is not surjective (`z ∉ K(z²)`). So the second "if and only if" is false in the direction "Birational ⇒ e(f) = 1".

   **Repair.** In `## Conventions` add: "A dominant rational map `f : X ⤏ Y` is *birational* if it is `φ.toRationalMap` for some `Scheme.PartialIso φ : X ⤏ Y`; its inverse `f^{−1}` is `φ.symm.toRationalMap`, independent of `φ` by the determination item of §1.1." Rewrite the §1.1 item as: "If `dim X = dim Y`, then `e(f) = 1` if and only if `f^*` is an isomorphism, if and only if `f` is birational; in that case `X` and `Y` are birational in Mathlib's sense `Scheme.Birational X Y`, and `f^{−1}` has pullback `(f^*)^{−1}`." (Proof of "`f^*` isomorphism ⇒ birational": the determination item gives `g : Y ⤏ X` with `g^* = (f^*)^{−1}`; `(g ∘ f)^* = id` forces `g ∘ f = id_X` and `f ∘ g = id_Y`, so `f` and `g` are inverse on dense opens.) In the "From Mathlib" contract say that `Scheme.Birational X Y` is the existence of a partial isomorphism between the schemes. Tested on the instance: `z ↦ z²` has `e = 2`, `f^*` not surjective, and is the rational map of no partial isomorphism, so all three conditions fail together; `id` satisfies all three.

3. **F03** (P3) §2.4 Check 3 asserts a normal scheme, an isomorphism and an Euler characteristic that are false

   **Location.** `design/README.md` line 281: "`V = Proj K[x, y, z]/(x² + t y²)` is normal with `K' = K(√t)` and `V ≅ ℙ¹_{K'}` … since `χ_K(O_V(n)) = 2(n + 1)`."

   **Claim.** `V` is normal, isomorphic to `ℙ¹_{K'}`, with `χ_K(O_V(n)) = 2(n + 1)`.

   **Witness.** The `K`-point `P = [0 : 0 : 1]` lies on `V` and `x² + t y² ∈ 𝔪_P²`, so `𝔪_P/𝔪_P²` has dimension 2: `O_{V,P}` is a one-dimensional local domain that is not regular, hence not normal. A plane conic has `χ(O_V(n)) = 2n + 1`, not `2n + 2` (`χ(O_V) = 1` since `h⁰ = 1`).

   **Repair.** Replace the Check by: "Over `K = 𝔽_2(t)`, `V = Proj K[x, y, z]/(x² + t y²)` is integral but not normal: at the `K`-point `[0 : 0 : 1]` the cotangent space has dimension `2`. Base change to `K'` instead gives the double line `(x + √t y)²` with fundamental cycle `2·[line]` and the same value `2·1`." The coefficient of `n` in `2n + 1` is `2`, so the computed value is unchanged and the Check now exhibits why (a) passes through the normalization.
