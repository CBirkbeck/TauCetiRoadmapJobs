## R02 (P3) — The distribution-function isomorphism divides by `μ(K)` with no `μ ≠ 0` hypothesis

**Location:** `TauCetiRoadmap/VonNeumannAlgebras/README.md:705–709`: "for a nonatomic finite Borel measure `μ` on a compact `K ⊆ ℝ` the distribution function `θ(t) = μ(K ∩ (−∞, t])/μ(K)` pushes `μ/μ(K)` forward to Lebesgue measure".

**Claim:** The zero measure is nonatomic and finite, and for it `θ` is `0/0`; the statement as written has no hypothesis excluding it. In the classification that follows, the nonatomic part of `μ` is zero exactly for the purely atomic algebras `ℓ∞(K)`, which the case split (`:709–710`) handles separately, so the theorem is only ever applied with `μ(K) > 0`; but the target itself quantifies over every nonatomic finite `μ`.

**Witness:** `K = [0, 1]`, `μ = 0`: `μ(K) = 0`, `θ` undefined, `L∞(K, μ) = 0` while `L∞([0,1], λ) ≠ 0`, so no isomorphism `f ↦ f ∘ θ` exists.

**Repair:** Add the hypothesis `μ ≠ 0` (equivalently `μ(K) > 0`) to the `θ` statement, and add `μ = 0` as a negative-control Check beside the `L∞([0,2], λ)` Check (`:719–720`). Tested: with `μ = λ` on `[0, 2]`, `μ(K) = 2 > 0`, `θ(t) = t/2`, and the pushforward of `λ/2` under `t ↦ t/2` is `λ` on `[0, 1]`, as the Check says.

## R03 (P3) — The single-generator weights are stated without the reason they must be `3⁻ⁿ`

**Location:** `TauCetiRoadmap/VonNeumannAlgebras/README.md:632–634`: "construct a single self-adjoint generator `a = Σ_n 3⁻ⁿ e_n` from a strongly dense sequence of projections `(e_n)`, recovering each `e_n` as a spectral projection of `a` (Jones, EP10, p. 23; Peterson, Lemma 2.8.8, p. 38, with weights `4⁻ᵏ`)".

**Claim:** The recovery of `e_n` as `P_a(B_n)` depends on the digit map `b ↦ Σ_n 3⁻ⁿ b_n` from `{0,1}^ℕ` to `ℝ` being injective (so that `B_n = {Σ 3⁻ᵏ b_k : b_n = 1}` is a Borel set whose spectral projection is `e_n`); the README's Check (`:691–693`) tests only orthogonal projections with distinct eigenvalues, where any distinct weights work, and so does not discriminate the base. The `(e_n)` of the construction are not orthogonal (a strongly dense sequence of projections of an abelian algebra), so the Check does not exercise the hypothesis the proof needs.

**Witness:** With weights `2⁻ⁿ` the sequences `(1, 0, 0, …)` and `(0, 1, 1, …)` give the same value `1/2`, so for `e₁ = 1_{A₁}`, `e_n = 1_{A_n}` with `A₁` disjoint from `A₂ = A₃ = ⋯`, the operator `a` takes the same value on `A₁` and on `A₂`, and `e₁` is not a spectral projection of `a`. With weights `3⁻ⁿ` the two values are `1/3` and `1/6`, distinct, and the digit map is injective (the ternary expansions with digits `0, 1` are unique).

**Repair:** Add one Check with two non-orthogonal commuting projections, for instance `e₁ = 1_{[0,1/2]}` and `e₂ = 1_{[0,1]} = 1` on `L²[0,1]`: `a = 3⁻¹ e₁ + 3⁻² e₂` takes the values `4/9` on `[0, 1/2]` and `1/9` on `(1/2, 1]`, so `e₁ = P_a({4/9})`; and state in the paragraph that the weights `3⁻ⁿ` (or any base at least `3`) are chosen so that the `0/1` digit expansion is injective, which weights `2⁻ⁿ` are not.
