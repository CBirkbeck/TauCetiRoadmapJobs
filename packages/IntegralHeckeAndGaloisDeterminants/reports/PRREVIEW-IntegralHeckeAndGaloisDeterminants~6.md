## R01 (P2) — Vaccarino's theorem can now be stated at the Tau Ceti pin, but `Suggested.lean` says it cannot

**Location:** `Suggested.lean:17–18`: "The determinant coordinate-ring and Vaccarino statements need the homogeneous divided-power algebra with its internal multiplication from DerivedModuleAlgebra §0.DP.2, absent at the pins."

**Claim:** The Roby algebra `Γ^d_A(R)`, with its internal product, is absent at the pins, so the Vaccarino headline (§0.4, README:809–818) cannot be stated.

**Witness:** Tau Ceti `2fd255d9` has `DividedPowerAlgebra.RobyAlgebra` (`TauCeti/RingTheory/DividedPowerAlgebra/RobyAlgebra.lean:340`), the internal product `homogeneousMul` (:92) and `RobyAlgebra.algHomEquiv` (:521). The file is absent at `a91d3aaf`. The statement below elaborates at the pins with one `sorry` warning and nothing else, and `simp_all` makes no progress on it.

**Repair:** Add `import TauCeti.RingTheory.DividedPowerAlgebra.RobyAlgebra`. Then state this in Layer 0:

```lean
/-- The commutator relation `ab ~ ba`. -/
def commRel (S : Type*) [Semiring S] : S → S → Prop := fun x y ↦ ∃ a b, x = a * b ∧ y = b * a

/-- The determinant coordinate ring `Z_A(R, d) = Γ^d_A(R)^ab`. -/
abbrev CoordinateRing (A : Type u) [CommRing A] (R : Type*) [Ring R] [Algebra A R] (d : ℕ) :=
  RingQuot (commRel (DividedPowerAlgebra.RobyAlgebra A R d))

/-- The generic `d × d` matrices `(x_{a,i,j})`, one for each letter `a`. -/
def genericMatrices (X : Type) (d : ℕ) :
    FreeAlgebra ℤ X →ₐ[ℤ] Matrix (Fin d) (Fin d) (MvPolynomial (X × Fin d × Fin d) ℤ) :=
  FreeAlgebra.lift ℤ fun a ↦ Matrix.of fun i j ↦ MvPolynomial.X (a, i, j)

/-- `E_X(d)`: generated by the characteristic coefficients of words in the generic matrices. -/
def vaccarinoSubalgebra (X : Type) (d : ℕ) : Subalgebra ℤ (MvPolynomial (X × Fin d × Fin d) ℤ) :=
  Algebra.adjoin ℤ {c | ∃ (w : List X) (k : ℕ),
    c = (genericMatrices X d (w.map (FreeAlgebra.ι ℤ)).prod).charpoly.coeff k}

/-- Vaccarino: the generic determinant identifies `Γ^d_ℤ(ℤ{X})^ab` with `E_X(d)`
([Chenevier], Theorem 1.15, p. 15). -/
theorem exists_vaccarino (X : Type) (d : ℕ) :
    ∃ ψ : CoordinateRing ℤ (FreeAlgebra ℤ X) d →ₐ[ℤ] MvPolynomial (X × Fin d × Fin d) ℤ,
      (∀ x, ψ (RingQuot.mkAlgHom ℤ (commRel _)
          ((DividedPowerAlgebra.RobyAlgebra.gamma ℤ (FreeAlgebra ℤ X) d).ground x)) =
        (genericMatrices X d x).det) ∧
      Function.Injective ψ ∧ ψ.range = vaccarinoSubalgebra X d := sorry
```
