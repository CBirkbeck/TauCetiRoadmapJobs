## R01 (P3) — The Serre equality clause is quoted for both signs; the source states it for one

**Location:** `README.md:1110`–1112, "§4.7.2.2, p. 48 (the bound `|N_X(q) − q − 1| ≤ g·m` … with equality only when every root `α` satisfies `α² + mα + q = 0`)". Unchanged since the previous review (its R01, not repaired).

**Claim:** Equality in the absolute-value bound forces `α² + mα + q = 0`.

**Witness:** Serre, *Lectures on N_X(p)*, p. 48 (cache `bdba7daa` lines 1737–1741) states the condition for the equality `N_X(q) − q − 1 = gm` only. The README's own worked example `1.2.ac` (line 1303, "Serre `≤ 1 · ⌊2√2⌋ = 2` with equality") has `N_1 − 3 = −2 = −g·m` and roots `1 ± i`, which satisfy `α² − 2α + 2 = 0`, not `α² + 2α + 2 = 0`; `1.2.c` (`N_1 = 5`, roots `−1 ± i`) is the case Serre's clause describes.

**Repair:** "with equality `N_X(q) − q − 1 = g·m` only when every root `α` satisfies `α² + mα + q = 0` (and `N_X(q) − q − 1 = −g·m` only when `α² − mα + q = 0`)". Tested: `1.2.ac` falls under the second clause (`1 ± i`, `α² − 2α + 2 = 0`) and `1.2.c` under the first (`−1 ± i`, `α² + 2α + 2 = 0`).
