## R01 (P2) — The pullback-orientation existence theorem is false on the empty manifold

**Location:** `TauCetiRoadmap/DifferentialGeometry/Suggested.lean:974–978`, `exists_isOrientationPreservingAt_pullback`; consumed by the definition `Manifold.Orientation.pullback` at 983–986 and by `isOrientationPreservingAt_pullback` at 988–992.

**Claim:** for every local diffeomorphism `f : M → M'` and every orientation `o'` of `M'` indexed by `ι`, there is an orientation of `M` indexed by the same `ι`.

**Witness:** take `M = Empty` modelled on `E = ℝ²`, `M' = ℝ` modelled on `E' = ℝ`, `ι = Fin 1`, `f` the empty map. `IsLocalDiffeomorph` (pinned `Mathlib/Geometry/Manifold/LocalDiffeomorph.lean:275`) is `∀ x : M, …`, vacuous. `o'` exists since `Fintype.card (Fin 1) = finrank ℝ ℝ`. But an `OrientationLift I Empty (Fin 1)` needs the field `card_eq : Fintype.card (Fin 1) = finrank ℝ ℝ²`, i.e. `1 = 2`; so `Manifold.Orientation I Empty (Fin 1)` is empty and the conclusion `∃ o, …` is false. The hypotheses `[FiniteDimensional ℝ E']`, `[IsManifold I n M]`, `1 ≤ n` all hold. For nonempty `M` a local diffeomorphism forces `finrank E = finrank E'`, so the empty case is the only failure, and `Manifold.Orientation.pullback`, defined by `Classical.choose` of this statement, is ill-typed there once the sorry is removed.

**Repair (tested on the refuting instance):** add `[Nonempty M]` to `exists_isOrientationPreservingAt_pullback`, `Manifold.Orientation.pullback` and `isOrientationPreservingAt_pullback` (or, equivalently, the hypothesis `Module.finrank ℝ E = Module.finrank ℝ E'`, which `card_eq` for `o'` and a local diffeomorphism at any point give). With `[Nonempty M]` the instance above is excluded and, for `M` nonempty, `mfderiv` at a point is a linear equivalence `E ≃ E'`, so a lift exists. Record the empty-manifold instance as a negative-control Check in README 2.2 ("Preserving maps and top forms", line 486), which at present states the pullback orientation with no nonemptiness or dimension clause.
