## R01 (P3) — §0.11b's negative control names the bounded expression, not the unbounded one

Location: `README.md` line 396 (second Check of §0.11b): "the opposite sign in the pole subtraction would give the unbounded `η⁻¹ + ζ′/ζ(1+η) ≈ 2η⁻¹`".

Claim: `η⁻¹ + ζ′/ζ(1+η)` is unbounded as `η → 0⁺`, of size `2η⁻¹`.

Witness: the Laurent expansion the same Check quotes, `ζ(s) = 1/(s−1) + γ + O(s−1)`, gives `ζ′/ζ(1+η) = −η⁻¹ + γ + O(η)`, so `η⁻¹ + ζ′/ζ(1+η) = γ + O(η)`, bounded, with limit `γ ≈ 0.5772`; at `η = 1` its value is `1 + ζ′/ζ(2) = 1 − 0.5700 = 0.4300` (I recomputed `−ζ′/ζ(2) = Σ Λ(n)/n² = 0.56996` from primes to `3·10⁶`). The expression that is `≈ 2η⁻¹` is `−ζ′/ζ(1+η) + η⁻¹`, i.e. the target with the pole subtracted with the wrong sign.

Repair: write the Check as "subtracting `−η⁻¹` instead of `η⁻¹` leaves `−ζ′/ζ(1+η) + η⁻¹ ≈ 2η⁻¹`, unbounded" (the target `−ζ′/ζ(1+η) − η⁻¹` stays bounded, tending to `−γ`). Checked on the instance that refuted the original: at `η = 1` the repaired expression is `0.5700 + 1 = 1.5700 ≈ 2`, and `−ζ′/ζ(1+η) + η⁻¹ = 2η⁻¹ − γ + O(η)` diverges.
