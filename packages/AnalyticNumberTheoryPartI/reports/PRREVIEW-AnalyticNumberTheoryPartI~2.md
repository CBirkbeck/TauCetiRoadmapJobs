## R01 (P2) — §1.7's route cites Jutila's Theorem 1 for a range it does not cover

Location: `TauCetiRoadmap/AnalyticNumberTheoryPartI/README.md` line 863 ("Jutila's Theorem 1, (1.8), gives … uniformly for `1/2≤σ≤1` and `T≥1`"), line 865; `Suggested.lean` line 112 ("Jutila's form implies it").

Claim: Jutila (Math. Scand. 41, Theorem 1, (1.8)) proves `Σ_{q≤Q}Σ*_χ N(σ,T,χ) ≪_ε (Q²T)^((2+ε)(1−σ))` for all `1/2 ≤ σ ≤ 1`, from which `selberg_zero_density` follows by `Q^(4+2ε)T^(2+ε) ≤ Q^(5+2ε)T^(3+2ε)`.

Witness: jutila1977 (the cached OCR of the Math. Scand. download) line 58 states Theorem 1 for `4/5 ≤ α ≤ 1` (its (1.7) is the single-modulus bound `N(α,T,q) ≪ (qT)^((2+ε)(1−α))`, which at `q = 1` and `α` down to `1/2` would be the open density hypothesis for `ζ`); line 229 opens the proof with "for `4/5 ≤ α ≤ 1−ε` the assertions follow from [6]" (line 586: Huxley–Jutila, *Large values of Dirichlet polynomials IV*); line 56 says the paper extends the density hypothesis "to the interval [4/5, 1]". Nothing in the paper, and no other input named in §1.7, bounds the count on `1/2 ≤ σ < 4/5`.

The target statement itself survives: on `1/2 ≤ σ ≤ 4/5` Montgomery's large-sieve density theorem gives `(Q²T)^(3(1−σ)/(2−σ))(log QT)^9`, and `3/(2−σ) ≤ 5/2` there, so the main term is at most `(Q⁵T^(5/2))^(1−σ) ≤ (Q⁵T³)^(1−σ)`, while `(log QT)^9 ≤ C_ε (QT)^(ε(1−σ))` because `1−σ ≥ 1/5`. This is the two-range route the previous review asked for.

Repair: in §1.7 replace "uniformly for `1/2≤σ≤1`" by "for `4/5≤σ≤1`", and add the lower range: "for `1/2≤σ≤4/5` use Montgomery, *Topics in multiplicative number theory*, LNM 227, Theorem 12.1 (or Huxley–Jutila, *Large values of Dirichlet polynomials IV*, Acta Arith. 33 (1977)): `Σ_{q≤Q}Σ*_χ N(σ,T,χ) ≪ (Q²T)^(3(1−σ)/(2−σ))(log QT)^9`; since `3/(2−σ) ≤ 5/2` and `1−σ ≥ 1/5`, the logarithm is absorbed into `(QT)^(ε(1−σ))` and the bound is at most `C_ε(Q⁵T³)^(1−σ)`." Add both works to the References, and change the docstring of `selberg_zero_density` to "Jutila's bound for `σ ≥ 4/5` and Montgomery's for `σ ≤ 4/5` imply it". Tested on the instance that refutes the current wording: at `σ = 3/4`, `Q = 1`, the current route asserts `N(3/4,T) ≪ T^((2+ε)/4)`, which no cited theorem gives; the repaired route gives `N(3/4,T) ≪ T^(3/5)(log T)^9 ≤ C_ε T^((3+ε)/4)`, which is what the signature needs.
