## R02 (P2) — Böckle's numerical criterion (`finite_presentation_complete_intersection`) is a stated target of ClassicalSerreModularity §I.2 and a special case of DeformationAndDerivedPatchingAlgebra §3.5

Location: README §10.2 lines 1625–1629 and `Suggested.lean` lines 88–108.

Claim: the headline `Presentations.finite_presentation_complete_intersection` (complete DVR `O`, `R ≅ O[[x₁,…,x_n]]/(f₁,…,f_m)` nonzero and finite over `O`, `m ≤ n` ⇒ `m = n`, `(π,f)` regular, `R` flat, `R[1/π] ≠ 0`) is planned by two earlier roadmaps. ClassicalSerreModularity §I.2 (README line 503) states, as its own criterion, "if `O` is a complete DVR with uniformizer `π`, `A = O[[x₁,…,x_n]]`, and `f₁,…,f_m` lie in the maximal ideal with `m ≤ n`, and the nonzero local quotient `R` has the same residue field and is finite over `O`, then `m = n` and `R` is a finite flat complete intersection", with the regularity of `(π,f₁,…,f_n)` and the nonempty characteristic-zero fibre; it derives it from DeformationAndDerivedPatchingAlgebra §§3.4 and 3.14. DeformationAndDerivedPatchingAlgebra §3.5 (README, "Dimension criteria for formal equations", Paškūnas–Quast Lemma 3.9) states the general form: `A` complete local Cohen–Macaulay, `B = A[[X₁,…,X_r]]/(f₁,…,f_t)` nonzero with `dim B ≤ dim A + r − t` ⇒ equality and the list is regular, `B` is a complete intersection when `A` is, and `B` is `A`-flat when `dim(B/m_A B) ≤ r − t`. With `A = O` and `B = R` finite over `O`: `dim R ≤ 1 ≤ 1 + n − m` gives `m = n`, regularity of `f`, and the closed fibre has dimension `0 = n − m`, so flatness; `π` is then `R`-regular, so `(π,f)` is regular and `R[1/π] ≠ 0`. The headline here is a one-step specialisation of a supplier's target and is not this roadmap's theorem. (Its hypothesis `hf`, that every `f i` lies in the maximal ideal, is also implied by `Nontrivial R`.)

Witness: ClassicalSerreModularity README line 503; DeformationAndDerivedPatchingAlgebra README §3.5 (`roadmaps show --pr 1034`); Böckle `bockle-appendix-2003` lines 140–153 is the same statement.

Repair: delete `Presentations.finite_presentation_complete_intersection` from `Suggested.lean`; in §10.2 import DeformationAndDerivedPatchingAlgebra §3.5 (the earliest owner) with the specialisation `A = O` spelled out, and cite ClassicalSerreModularity §I.2 for Böckle's form; keep §10.2's Checks as Checks of the imported statement. After R01 and R02 the Lean file states `additiveStrongApproximationAwayFromPlace` alone, which is correct for a roadmap whose other headlines are not statable at the pins (GlobalNumberFields Layer 6 on main omits only the archimedean places, so the away-from-any-one-place statement is this roadmap's).
