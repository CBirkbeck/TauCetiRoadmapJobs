## R01 (P2) — The orthogonality Check of 4.1 at `λ' = 3.3`, `(m, n, m', n') = (1, 0, 0, 0)` does not have `λ + n = λ' + n'`

The Check (in 4.1, the bullet "Orthogonality at `λ = 2.3`", line 826) says the integral is `0` at `λ' = 3.3`, `(m, n, m', n') = (1, 0, 0, 0)`, "where `λ + n = λ' + n'` but the `w`-integral vanishes". With these data `λ + n = 2.3` and `λ' + n' = 3.3`. The integral is indeed `0`, but because both factors vanish: the `α`-integral is `∫_0^{2π} e^{−iα} dα = 0` and the `w`-integral is `0` since `m ≠ m'`. So the sentence is false as written, and the case it is meant to test, in which the `α`-integral is `2π` and only the orthogonality of 3.2 gives `0` (the case that separates `δ_{λλ'} δ_{nn'}` from the bare condition `λ + n = λ' + n'`), is not tested.

Computed here with the matrix elements of 4.1 at `δ = 0.37`: at `(1, 0, 0, 0)` the `α`-integral is `0` and the `w`-integral is `0`; at `(m, n, m', n') = (0, 1, 0, 0)` and at `(1, 1, 1, 0)` one has `λ + n = λ' + n' = 3.3`, the `α`-integral is `2π` and the `w`-integral is `0`. The smallest change: replace `(1, 0, 0, 0)` by `(0, 1, 0, 0)` (or `(1, 1, 1, 0)`).

## C01 — The matrix realization of 0.2 is the oscillator group law of SpecialFunctionsGroupModels §0.2, and the bullet does not say so

In 0.2 (line 169) "`toMatrix` is multiplicative" is listed under "Prove" as a sanity check of this roadmap's definitions. Since `Oscillator` is defined with the law of the oscillator matrices and `Oscillator.toMatrix g` is `oscillatorMatrix g.w g.α g.δ`, the statement is, after unfolding, the supplier's target "Oscillator group law" (`oscillatorMatrix_mul` in its Lean file) read from right to left; an implementer who has the supplier's theorem has nothing left to prove. The `*Needs:*` line names the section, but the bullet reads as an independent target. Say in the bullet that it is SpecialFunctionsGroupModels §0.2's oscillator group law transported to `Oscillator`.
