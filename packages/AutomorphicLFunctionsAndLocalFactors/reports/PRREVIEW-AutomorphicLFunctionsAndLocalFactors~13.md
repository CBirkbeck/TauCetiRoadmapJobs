## R01 (P2) — AL.3.3.5 derives the existence of the newform level from smoothness alone; the inference is backwards

**Location:** `:1587`, AL.3.3.5 Generic finite-place newforms:

> The depth c is defined before any analytic input: every nonzero vector is fixed by a principal congruence subgroup, which lies in some `K₁(P^m)`, so the least depth with nonzero invariants exists

**Claim:** A vector fixed by the principal congruence subgroup `K(P^m)` is fixed by a subgroup *of* `K₁(P^m)`. That does not make it fixed by `K₁(P^m)` itself. The existence of a level m with `π^(K₁(P^m))≠0` needs genericity.

- Humphries, Godement–Jacquet tests, Theorem 3.2, p.3, states this existence as part of Jacquet–Piatetski-Shapiro–Shalika's Théorème (5).
- The README already treats the rank-two case as a theorem. AL.2.2.2 cites Casselman's Kirillov-model proof for it. `GL2Blueprint.newvectorLevelExists` (`Suggested.lean:366`) also keeps the hypothesis `hinf`.
- The sentence at `:1587` would make `hinf` unnecessary, and it would prove existence for every smooth `π`.

The sentence also places this step "before any analytic input". The build order at the end of the same paragraph would then be wrong as well.

**Witness:** Take a ramified χ and `π=χ∘det` on `GL₂(F)`.

- Its vector is fixed by `K(P^(c(χ)))`.
- But `diag(u,1)∈K₁(P^m)` for every m, and it acts by `χ(u)≠1` for some unit u.
- So `π^(K₁(P^m))=0` for every m.

**Repair:**

1. At `:1587`, replace the quoted sentence and its clause "and vanishing below c holds by minimality" with:

   > Genericity gives a level m with `π^(K₁(P^m))≠0` (Jacquet–Piatetski-Shapiro–Shalika, Théorème (5), as stated in Humphries, Godement–Jacquet tests, Theorem 3.2, p.3). Smoothness alone does not, since a vector fixed by the principal congruence subgroup `K(P^m)⊆K₁(P^m)` need not be fixed by `K₁(P^m)`. Let c be the least such m; vanishing below c holds by minimality.

2. In the order sentence of the same paragraph, change "and only then the dimension-one, essential-vector and conductor assertions" to "and only then the existence of c and the dimension-one, essential-vector and conductor assertions".

3. Add this Check at `:1589`:

   > A ramified determinant character `χ∘det` of `GLₙ(F)`, `n≥2`, is fixed by `K(P^(c(χ)))` but has no nonzero `K₁(P^m)`-fixed vector for any m, because `diag(u,1,…,1)∈K₁(P^m)` acts by `χ(u)`. The existence of c needs genericity.

**Tested:**

- **`χ∘det`, χ of conductor 1.** The repaired text asserts nothing for this π, because π is not generic. A `ψ_N`-functional ℓ would satisfy `ℓ(v)=ψ(x)ℓ(v)` for every x, so `ℓ=0`. The new Check gives `π^(K₁(P^m))=0` for all m.
- **`St⊗χ`, `c(χ)=1`.** Here c=2, which agrees with AL.2.2.3's Check (`:1316`).
- **Unramified principal series.** Here c=0.
- **The Lean statement.** `AL3.genericNewform` (`Suggested.lean:682`) is correct as stated and needs no change. Its hypotheses `hell` and `hwhit` already exclude `χ∘det`.
