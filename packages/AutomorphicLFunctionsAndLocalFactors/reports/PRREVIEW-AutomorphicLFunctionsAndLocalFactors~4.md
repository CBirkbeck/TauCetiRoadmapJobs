A scratch file stating it elaborated at the pins with `lake env lean` (exit 0, the `sorry` warning only): an irreducible smooth admissible `Representation ℂ (GL (Fin (n+1)) F) V`, a Haar measure on `GL (Fin (n+1)) F`, an additive Haar measure on `Matrix (Fin (n+1)) (Fin (n+1)) F`, a nontrivial continuous `AddChar F Circle`, the modulus `a : F → ℝ` as in the rank-one theorem, matrix coefficients `g ↦ ℓ (π g v)` with `ℓ` of open stabilizer, locally constant compactly supported `Φ`, the Fourier transform through the trace pairing `LinearMap.mk₂ F (fun X Y => (X * Y).trace) …`, and the conclusion `∃ P Pd c ε k, P.eval 0 = 1 ∧ Pd.eval 0 = 1 ∧ ε ≠ 0 ∧ ∀ v ℓ Φ, ∃ Z Zd, MeromorphicOn Z univ ∧ MeromorphicOn Zd univ ∧ (Z agrees with ∫ g, ℓ (π g v) * Φ g.val * (a g.val.det)^(s + n/2) ∂ν on c < Re s) ∧ (Zd agrees with the same integral of `ℓ (π g⁻¹ v)` against the transform of Φ at −g.val) ∧ Differentiable ℂ (fun s => Z s * P.eval (q^(-s))) ∧ ∀ s₀, (fun s => Zd (1-s) * Pd.eval (q^(s-1))) =ᶠ[𝓝[≠] s₀] fun s => ε * (q^(-s))^k * Z s * P.eval (q^(-s))`, with `q = Nat.card (IsLocalRing.ResidueField 𝒪[F])`; a second clause, `∀ s₀, ∃ v ℓ Φ` whose continued `Z · P(q^{-s})` is nonzero at `s₀`, elaborated as well.
