## R01 (P3) — §1.1's per-weight gloss of the Kostant criterion is an "iff" only when quantified over all dominant weights

Location: README line 557, "ACC's defining condition, that `w` carry `B`-dominant weights to Levi-dominant weights, is `kostantPositive` for this pair: for a dominant `λ`, `⟨wλ, α^∨⟩ ≥ 0` for every positive root `α` of the Levi iff `w⁻¹α > 0`."

Claim: for a fixed dominant `λ`, Levi-dominance of `wλ` is equivalent to `w⁻¹Φ_M⁺ ⊂ Φ⁺`.

Witness: `n = 2`, `w = (0 1) ∈ S₂×S₂`, `λ = 0`: `⟨wλ, α^∨⟩ = 0 ≥ 0` for both Levi roots, but `w⁻¹(e₀−e₁) = e₁−e₀ < 0`. For `λ = ρ = (3,2,1,0)` the pairings are `(−1, 1)`, so the left side fails only for a weight with `⟨λ, (e₀−e₁)^∨⟩ > 0`. The true equivalence is the set inclusion `w(X*(T)⁺) ⊆ X*(T)^{+,M}` iff `w⁻¹Φ_M⁺ ⊂ Φ⁺`, which is ShimuraData §3.11 `kostantConeCriterion` (its proof sketch chooses "an integral strictly dominant weight to witness failure"), and ACC's own definition is that inclusion (`acc` lines 384–386, printed p. 906). Nothing in the roadmap is derived from the sentence: the representatives themselves are imported, and §§1.2, 1.4, 1.5, 3.23, 3.36–3.37 use only the membership criterion and the lengths, so this is a precision defect in explanatory prose, not a target.

Repair: replace the clause after the colon by "`w` carries every `B`-dominant weight to a Levi-dominant one iff `w⁻¹α > 0` for every positive root `α` of the Levi (ShimuraData §3.11, `kostantConeCriterion`)", and add §3.11 to §1.1's *Needs:* line and to the ShimuraData supplier row. Tested on the instance: with the quantifier over all dominant weights, `w = (0 1)` fails the left side at `λ = ρ` and the right side at `α = e₀−e₁`, as required.
