1. **F01** (P3) 1.1's continuity bullet is narrower than what 3.1 uses

   Location: `packages/Varifolds/design/README.md` line 290–291, "For an injective linear map L : E → F and P ∈ G(E, k), the projection onto L(range P) depends continuously on (L, P) on the set of such pairs"; `plan.json` 1.1 API "image plane". Consumer: README line 525–527, 3.1, "(x, P) ↦ (f(x), P_{df_x(range P)}) is continuous on the open set {J_S f(x) ≠ 0}".

   Claim: continuity is stated only for L injective on all of E, while 3.1 needs it on the set where df_x is injective on range P only.

   Witness: f(y) = (y_1, 0) on ℝ², S = span(e_1): J_S f = normDet(df|_S) = 1 ≠ 0, so (0, P_S) lies in 3.1's open set, but df = diag(1, 0) is not injective, so the pair (df, P_S) is outside the set 1.1's bullet covers. The statement 3.1 makes is true (with Q = L ∘ P, the projection onto range Q is Q (Q*Q)⁺ Q*, continuous where rank Q = k, an open condition), but its input in 1.1 does not supply it.

   Repair: in 1.1 state the bullet as "For a linear map L : E → F and P ∈ G(E, k) with L injective on range P (an open set of pairs), the projection onto L(range P) depends continuously on (L, P)", and make the same change to the plan.json API sentence. Tested on the witness: L = diag(1, 0) is injective on span(e_1), the pair is in the open set, and the projection onto L(span e_1) = span(e_1) is P_S, continuous in (L, P) near it.

2. **F02** (P3) 6.4's conclusion uses [Σ] where 2.3 has not defined it

   Location: `packages/Varifolds/design/README.md` line 1032–1034, "Then V = θ_0 [Σ] for a constant θ_0 ≥ 0; if V ≠ 0, Σ is closed in W and has locally finite area".

   Claim: the first clause writes [Σ] for every connected C² embedded Σ, while 2.3 defines [Σ] = v(Σ, 1) only when Hᵏ(Σ ∩ K) < ∞ for every compact K ⊆ W.

   Witness: W = ℝ², Σ = graph of t ↦ sin(1/t) over (0, 1), a connected C² embedded 1-submanifold with H¹(Σ ∩ B̄_2(0)) = ∞; V = 0 is stationary with spt‖V‖ = ∅ ⊆ Σ, so 6.4 applies and asserts V = θ_0[Σ], where [Σ] is undefined. (When V ≠ 0 the second clause makes [Σ] defined, so the theorem's content is unaffected.)

   Repair: state the conclusion as "either V = 0, or Σ is closed in W with Hᵏ(Σ ∩ K) < ∞ for every compact K ⊆ W and V = θ_0 [Σ] with θ_0 > 0" (Simon1983 41.1 and 41.2(1)), and change the plan.json 6.4 statement to match. Tested on the witness: V = 0 takes the first branch; v(L, 3) on a line takes the second with θ_0 = 3.
