Corrections made or carried through:

1. Stable central distributions form a complex submodule; only very stable distributions are given a subalgebra. The convolution module action uses inversion explicitly: δ₁(z∗f^vee)=z(f). No closure of the entire stable submodule under multiplication is asserted.
2. The forward character functor uses V_μ dual; the reverse uses V_μ and starts at i₁!. The p. 13 extension-index error is confirmed by H26 line 622 against H26 line 411. The all-weight comparison carries source, target, basic label, modification direction and representation duality. HeckeStacksAndLocalShtukas HS1.2 and HS3.10 fix a degree/Kottwitz convention; its torus degree witness is retained instead of inferring a convention from equal one-dimensional fibres.
3. The averaging weight is 4mρ for positive roots of Ĝ, hence positive coroots of G. The B₂ computation gives root sum (3,1), coroot sum (4,2), and μ₁=(8,4). This confirms the Hansen notation correction against FU25 line 717 and line 719.
4. In the HKW sign identity 2ρ is the full positive-root sum once. HKW22 line 847–850 and line 3492–3498 give the conventions. The GL₂/quaternion exponent is 1, with sign −1; doubling the sum gives exponent 2 and the false sign +1.
5. All means divide by a positive finite class cardinality and all weight kernels by d_m>0. Rank zero is a separate torus case; m=0 defines a representation but is excluded from estimates involving 1/m. The Fourier bound uses a root with χ(α)≠1, so the denominator |1−χ(α)| is nonzero.
6. D_ind in the full finite character span is distinguished from its intersection with D_temp. D_ell means Arthur's elliptic tempered summand. The central-invariance contract refers to ordinary cuspidal/elliptic summands; it does not assume all Bernstein elements preserve stable characters, which would beg the main theorem.
7. The character limit is weighted by the discriminant and uniform on a compact set of representatives, rather than a full conjugacy saturation. The cuspidal limit states the exact quantifier ∃C_(Ξ,f)≥0, ∀m≥1. The stability proof uses only temperedness of Ξ=z·Θ before its conclusion.
8. Atomicity excludes zero and allows arbitrary complex coefficients for competitors. The six proper nonempty 0/1 partial sums of (1,1,1) miss span{(1,2,0),(1,1,1)}, while (1,2,0) is a smaller stable competitor. This distinguishes the accepted definition from testing packet subsums. One inherited Check also needed a mathematical repair: a nonzero combination of two torus characters need not have both coefficients nonzero; the two-constituent non-atomic test now requires both coefficients nonzero, and records (1,0) as an atomic singleton control.
9. Kernel inclusion has direction ker Ψ_(G*)⊆ker Ψ_G. Surjectivity is onto the FS image algebra, and the Levi argument uses surjectivity onto that image only. Reverse Hecke is compared modulo induced characters, without assuming its output lies in D_ell.
10. All 45 advertised own API names and all own Check names are prose in the README. None is padded into Suggested.lean. The design's generic diagonal-scalar, finite-average and quotient-factorization signatures are excluded from the acceptance file because they do not state these headline theorems on their actual carriers. The same finite examples remain explicit README Checks.
11. The residue repair addresses 19 matches of the singular mathematical word “packet”, including occurrences in a gap slug. Only the affected README prose and headings were rephrased, using L-packets or the regular supercuspidal construction. The supplier gap is now gap:regular-supercuspidal-atomicity; its needs sentence and every README reference agree with the gaps entry. Every mathematical assertion, hypothesis, source locator, API fact, Check and worked example is preserved. Suggested.lean, metadata.toml and sources.toml were untouched; no acceptance signature or elaboration result changed.
