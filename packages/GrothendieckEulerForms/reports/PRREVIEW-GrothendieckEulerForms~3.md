## R01 (P2) — `isGradedExtComparison_toModuleCat_pathAlgebra` is false without finite-dimensionality of `kQ`

**Location.** `TauCetiRoadmap/GrothendieckEulerForms/Suggested.lean` lines 242–251: hypotheses `(Q : Type u) [Quiver.{v} Q] [Finite Q]`, `hX : gradedFiniteModules … X`, `hY : gradedFiniteModules … Y`; README line 467, "for finitely generated graded modules `X`, `Y` over the path-length-graded `kQ`".

**Claim.** For every quiver with finitely many vertices and every pair of finitely generated graded `kQ`-modules, `⊕_j Ext^n_gr(X, Y{j}) ≃ₗ[k] Ext^n(U X, U Y)` in every degree `n`.

**Witness.** At the pin `gradedFiniteModules 𝒜 M` is `Module.Finite A M` (`Algebra/Category/GradedModuleCat/CartanMap/Basic.lean:101`), `IsGradedExtComparison` asks for a `k`-linear equivalence in each degree (`ExtEuler/Graded/ForgetGrading.lean:86`), and `[Finite Q]` constrains only the vertex type. Take `Q` with one vertex and two loops `x`, `y` (a finite quiver), so `kQ = k⟨x,y⟩` with `x`, `y` in degree 1. Let `w_n = x yⁿ` (`n ≥ 0`), `Ω = ∑_n kQ·w_n`, `X = kQ/Ω` and `Y = S = kQ/(x,y)`. Both are cyclic, hence finitely generated. No `w_m` is a suffix of a different `w_n` (the length-`(m+1)` suffix of `x yⁿ` is `yᵐ⁺¹ ≠ x yᵐ`), so `Ω` is free on the `w_n`: `0 → ⊕_n kQ·w_n → kQ → X → 0` is a graded projective resolution with `w_n` in degree `n+1`. The restriction map `Hom(kQ, S) → Hom(Ω, S)` is zero (`w_n` acts by zero on `S`), so `Ext¹(X, S) = Hom(Ω, S) = ∏_{n∈ℕ} k`, of uncountable dimension by Erdős–Kaplansky; while `Hom_gr(kQ·w_n, S{j})` is `k` for exactly one `n` per `j` and `0` otherwise, so `⊕_j Ext¹_gr(X, S{j}) = ⊕_{n∈ℕ} k`, of countable dimension. No `k`-linear equivalence exists in degree `n = 1`. (With `x yⁿ` replaced by `yⁿ x` the same holds under the other path-composition convention; with infinitely many arrows between two vertices the same construction works with `Finite Q` and one loop.)

**Repair.** Add the pinned hypothesis the ungraded comparison uses, `[FiniteDimensional k (pathAlgebra k Q)]` (`RepresentationTheory/GrothendieckGroup/Quiver/ExtEuler.lean:60`, from which `finite_hom_of_module_finite_pathAlgebra` and `isAcyclic_of_module_finite_pathAlgebra` give finite arrows and acyclicity). Then finitely generated modules are finite-dimensional over `k`, every syzygy of a finite-dimensional graded module is finitely generated, `Hom(P, Y) = ⊕_j Hom_gr(P, Y{j})` termwise on a finitely generated graded free resolution, and the comparison holds in every degree for every `Y`. Tested: the statement with that one instance added elaborates at the pins (exit 0, `sorry` the only warning), and the two-loop quiver no longer satisfies the hypotheses (`k⟨x,y⟩` is infinite-dimensional). In the README (line 467) say "finite acyclic quiver" in the graded sentence as the ungraded one at line 462 does, and in the Lean docstring (line 236) replace "a finite quiver" by "a finite acyclic quiver".

## R03 (P3) — `gradedCartanMap_bijective` is stated more generally than the README

**Location.** `Suggested.lean` lines 204–209: `{k : Type u} [CommRing k] {A : Type v} [Ring A] [Algebra k A] (𝒜 : ℤ → Submodule k A)`, finitely generated modules; README lines 383–388: "a graded finite-dimensional algebra with graded simples and graded projective covers".

**Witness.** The elaborated type (scratch `#check`) quantifies over every `k`-algebra `A`, every family `𝒜`, and `gradedFiniteModules = Module.Finite A`; the pinned `gradedCartanMap` is defined "for arbitrary grading data" (`CartanMap/Basic.lean:485–507`). The wider statement is true: `P` = finitely generated projective underlying module is extension-closed and closed under kernels of surjections between its objects (such a surjection splits), the syzygies of an ambient finite `P`-resolution are images of finitely generated modules, so the hypothesis transfers to the induced structure and the graded resolution theorem (`Laurent/Resolving.lean:126`) applies; the pinned ungraded `cartanEquiv` (`ModuleCat/CartanMap/Basic.lean:686`) uses the same hypothesis shape.

**Repair.** In the README sentence at line 386 state the generality the Lean has: for any `k`-algebra `A` with grading data `𝒜` and finitely generated graded modules, under the resolution hypothesis in the canonical exact structure of all graded modules; the finite-dimensional case is the instance Layer 4 uses.
