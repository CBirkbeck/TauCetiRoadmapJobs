1. **F01** (P3) `ha₀` is redundant in the principal-unit theorem

   **Location.** `Suggested.lean` line 178, `(ha₀ : IsUnit (1 - 4 * a₀))` in `not_anisotropic_quadraticPfister_of_residue_eq_one`; README line 1323, "`a₀ ∈ O` and `1 − 4a₀ ∈ Oˣ`".

   **Claim.** The conclusion holds without `ha₀`. If the residue characteristic is `2`, then `4 ∈ 𝔪` and `1 − 4a₀ ≡ 1` is a unit automatically. If it is not `2`, then `2 ∈ Oˣ` and `X² − εᵢ` has the simple residual root `1` (`εᵢ ≡ 1`, derivative `2`), so `εᵢ = c²` with `c ∈ Oˣ` by `HenselianLocalRing`; pairing the blocks `S` and `S ∪ {i}` (weights `w_S` and `−c² w_S`), the vector with `v` in block `S` and `c⁻¹ v` in block `S ∪ {i}` has value `w_S q(v) − c² w_S c⁻² q(v) = 0` for every `v ≠ 0`, whatever `a₀` is.

   **Witness.** `K = ℚ₃`, `O = ℤ₃`, `m = 1`, `ε = 4 ≡ 1 mod 3`, `a₀ = 1/4 ∈ ℤ₃`: `1 − 4a₀ = 0`, not a unit, and the form `(x + y/2)² − 4(z + w/2)²` vanishes at `(2, 0, 1, 0)`: `4 − 4 = 0`. The repair report's own table says the same ("true without `ha₀`") and kept the hypothesis for the route through 4.1.

   **Repair.** Drop `ha₀` from the Lean statement and from the README sentence, and split 4.2's route by residue characteristic (characteristic two: `1 − 4a₀` is a unit and 4.1 applies; otherwise Hensel makes `εᵢ` a square and the form is `ρ ⊥ −ρ`). Tested: the statement without `ha₀` is the one proved above on the `ℚ₃` instance, and removing a hypothesis changes no other declaration. If the author prefers the uniform "unit Pfister form" hypothesis, the README must say in 4.2 that `1 − 4a₀ ∈ Oˣ` is carried for uniformity and is not needed.

2. **F02** (P3) 4.1's lifting polynomial is not made monic by `t ↦ 1/t`

   **Location.** README lines 1300–1302: "restricting to the line `x + t eⱼ` gives a quadratic polynomial with a simple residual root, which after `t ↦ 1/t` becomes monic and lifts by `HenselianLocalRing.TFAE`".

   **Claim.** The polynomial is `c t² + b t + q(x)` with `c = q(eⱼ)`, `b = b_q(x, eⱼ) ∈ Oˣ` and `q(x) ∈ 𝔪`. Inverting the variable gives `q(x) s² + b s + c`, whose leading coefficient lies in `𝔪`; Mathlib's `HenselianLocalRing` (`RingTheory/Henselian.lean:108–111`) and both items of `HenselianLocalRing.TFAE` (line 119) require a monic polynomial, so the step as written does not apply when `c` is not a unit.

   **Witness.** `K = 𝔽₂((t))`, `ε = (1 + t)`, `a₀ = t`: the form is `[1, t] ⊥ (1 + t)[1, t]`, `x = (1, 0, 1, 0)` has `q(x) = t`, `j = (0, 1)` has `b = 1` and `c = t`; the polynomial is `t s² + s + t`, and `s ↦ 1/u` gives `t u² + u + t`, not monic. Every `j` with nonzero residual polar value has `q(eⱼ) = w_k t ∈ 𝔪` here.

   **Repair.** Replace the clause by: "if `c = q(eⱼ) = 0` take `t = −q(x)/b`; otherwise `u = c t` satisfies the monic `u² + b u + c q(x)`, with simple residual root `0`, which lifts by `HenselianLocalRing`; then `t = u/c ∈ K` and `x + t eⱼ ≠ 0`". Tested on the witness: `u² + u + t²` has the root `u ∈ 𝔪` with `u ≡ t²`, and `s = u/t` solves `t s² + s + t = 0`.
