## R01 (P1) — The canonical presentation of a cofinite Fuchsian group has no owner

- **Location.**
  - README lines 656–660: "Its standard presentation (FuchsianOrbifolds Layer 2 items 4–5, with the genus identified by Layer 5 item 7) has at most `d_C` generators". The same input is used again at lines 680–681.
  - README lines 1074–1075: "FuchsianOrbifolds Layer 2 items 4–5 give `Γ₀` the presentation `⟨a₁, b₁, …, a_g, b_g | ∏[a_i, b_i]⟩`".
  - The *Needs:* lines 717 and 1095.
- **Claim.** Two steps need the canonical presentation:
  - the generator bound `2g + r + c` in §1.4;
  - the surjection `Γ₀ → Q` in §3.4, which sends `a₁, a₂, a₃` to generators of `Q` and every other generator to `1`.

  The cited items state only the side-pairing presentation of a Dirichlet polygon, and no supplier converts it to canonical generators. A generic Dirichlet polygon of a closed genus-`g` surface has `12g − 6` sides, so it has `6g − 3` side pairings and its relators are vertex-cycle words, not `∏[aᵢ,bᵢ]`. Neither the count `2g + r + c` nor the map that sends `bᵢ ↦ 1` can be read off it.
- **Witness.**
  - FuchsianOrbifolds README at 1e1ceeb, Layer 2 item 4: `Subgroup.IsCofinite.exists_sidePairing_relatorQuotientTo_bijective`. Item 5 reads off "the presentation by item 3".
  - Tau Ceti `Analysis/Complex/Fuchsian/DirichletDomain/Cofinite.lean:79`: "`Γ` is presented by the side pairing of this polygon".
- **Repair.**
  - Add a named §1.4 target for the standard presentation, with a locator the author has checked: a cofinite `Γ` of signature `(g; m₁,…,m_r; c)` is generated by elements `a_i, b_i, x_j, p_k` with `x_j^(m_j) = 1` and `∏[a_i,b_i]∏x_j∏p_k = 1`.
  - Give it a route: the side-paired polygon of FuchsianOrbifolds Layer 2 items 3–5, brought to normal form by FreeGroupsAndLimitGroups §§6.0b–6.1a, which are on main.
  - For the closed torsion-free case of §3.4 a second route is available: Tau Ceti `TauCeti.UniversalCover.deckFundamentalGroupEquiv`, ComplexCurveModuli D0 item 1 (normal forms) and AlgebraicTopology Stage 1 (van Kampen).
  - Cite this target at lines 656–660, 680–681, 717, 1074–1075 and 1095.
  - Tested on the refuting instance: for a closed genus-3 `Γ₀` whose Dirichlet polygon has 30 sides, the target gives the six generators `a₁,b₁,…,b₃` with the relation `∏[aᵢ,bᵢ]`. The map `a₁,a₂,a₃ ↦ (1,1),(3,0),(5,0)` with `bᵢ ↦ 1` then respects that relation and is onto `Q` (all 32 elements are reached).
