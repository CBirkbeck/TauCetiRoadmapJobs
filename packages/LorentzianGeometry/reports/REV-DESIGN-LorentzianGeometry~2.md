1. **F01** (P2) §5.4 null generators: "stay in `H` as long as they stay in `U`" needs `H ∩ U` closed in `U`

   Location: `packages/LorentzianGeometry/design/README.md` line 586, "the integral curves of `L` through points of `H ∩ U` stay in `H` as long as they stay in `U`"; the same in `plan.json` 5.4, "integral curves of L through H stay in H while in U".

   Claim: for a null hypersurface `H` of class `C²` (in the local sense of §5.1) and a `C¹` null normal `L` on an open `U`, an integral curve of `L` starting in `H ∩ U` remains in `H` while it remains in `U`.

   Witness: Minkowski `ℝ²`, `H = {t = x, x > 0}`, `U = ℝ²`, `L = ∂_t + ∂_x`. `H` is a hypersurface of class `C^∞` by §5.1 (at `p = (a, a)` take the neighbourhood `{x > 0}` and `f = t − x`, `df ≠ 0`, interior point), null at every point (`g⁻¹(df, df) = −1 + 1 = 0`), and `L` takes values in the radical `ℝ grad f = ℝ(−∂_t − ∂_x)`, so it is a `C¹` null normal along `H ∩ U`. The integral curve through `(1, 1)` is `s ↦ (1 + s, 1 + s)`; computed: at `s = −½` the point `(½, ½)` is in `H`, at `s = −1` the point `(0, 0)` has `t − x = 0` but `x = 0`, so it is not in `H`, and at `s = −1.5` the point `(−½, −½)` is not in `H`; all are in `U`. The Grönwall step of the proof sketch is local near `H`; the passage to the whole interval is an open–closed argument that needs the set of parameters with `γ(s) ∈ H ∩ U` to be closed, which fails when `H ∩ U` is not closed in `U`.

   Repair: state the bullet as "the set of parameters at which an integral curve of `L` through a point of `H ∩ U` lies in `H ∩ U` is open in its domain; when `H ∩ U` is closed in `U` (for instance a level set `u⁻¹(c) ∩ U` of an optical function, §5.3), the curve stays in `H` as long as it stays in `U`", and keep the generator-segment clause under the same closedness hypothesis; make the same change in `plan.json` 5.4. Tested on the instance: with `U' = {x > 0}`, `H ∩ U'` is closed in `U'` and the curve `s ↦ (1 + s, 1 + s)` is in `H` exactly for `s > −1`, the parameters at which it is in `U'`; for `U = ℝ²` the repaired statement only asserts openness, which holds (the parameter set is `(−1, ∞)`). The optical-function consequences of §5.4 and §5.3 are unchanged, since level sets are closed in `U`.
