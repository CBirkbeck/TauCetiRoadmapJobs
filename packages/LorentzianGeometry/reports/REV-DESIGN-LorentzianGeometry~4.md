1. **F01** (P2) §2.6 concatenation of causal curves lacks the junction condition

   Location: `packages/LorentzianGeometry/design/README.md` line 335, "restriction to a subinterval and concatenation of curves with matching endpoints preserve them"; `plan.json` 2.6, api `IsCausalCurve.comp_reparam`, "restriction and concatenation preserve causal, timelike, null curves".

   Claim: the concatenation of two causal (timelike, null) curves with a matching endpoint is causal (timelike, null).

   Witness: the roadmap's own Check at line 345: the curve with velocity `(1, 0)` on `[0, 1]` and `(−1, 0)` on `[1, 2]` is the concatenation of two timelike curves with matching endpoint `(1, 0)`, and `η((1, 0), (−1, 0)) = 1 > 0`, so the one-sided velocities at `s = 1` lie in opposite cones and the concatenation is not timelike, nor causal, by the definition at line 332.

   Repair: at line 335 write "restriction to a subinterval preserves them, and so does concatenation of two such curves with matching endpoint whose one-sided velocities at the junction lie in the closure of one time cone (automatic for two future-directed curves in a spacetime, §4.3)"; change the `plan.json` 2.6 api statement to match. Tested on the refuting instance: the junction condition fails for `(1, 0)` then `(−1, 0)` (opposite cones), so the bullet no longer applies; it holds for `(1, 1)` then `(1, −1)` (both in the closure of the cone of `e₀`), whose concatenation is the null curve of the same Check.

3. **F03** (P3) "of class `ℛ`" for functions and vector fields is used but not defined

   Location: `packages/LorentzianGeometry/design/README.md` line 314 ("a function `φ` of class `ℛ`"), line 316 ("functions `c > 0`, `v¹, …, vⁿ` of class `ℛ` on `M`"), line 318 ("a vector field `X` of class `ℛ`"); line 274 defines `IsBilinFormOfClass ℛ b` for pointwise bilinear fields only and says "the same predicate gives the class of … the coefficient fields of §2.5".

   Claim: the class `ℛ`, including `C^{k,α}`, of a scalar function and of a vector field on a manifold with corners is a defined notion.

   Witness: `IsBilinFormOfClass` takes `b : (x : M) → T_xM →L[ℝ] T_xM →L[ℝ] ℝ`; a function `M → ℝ` or a section of `TM` is not such a field, and for `ℛ = C^{k,α}` the only chart test defined is on bilinear coefficient maps.    Repair: in §2.3, after the definition of `IsBilinFormOfClass`, add one sentence defining the class `ℛ` of a function `M → ℝ` and of a vector field (a section of `TM`) by the same chart test (`C^k`: `ContMDiff` of order `k`; `C^{k,α}`: `ContDiffLocallyHolderOn k α` of the coordinate expression on every extended chart target), and add to the Algebra bullet (line 280) that a product of a class-`ℛ` function with a class-`ℛ` field, and the quotient by a nowhere-vanishing class-`ℛ` function, are of class `ℛ`.
