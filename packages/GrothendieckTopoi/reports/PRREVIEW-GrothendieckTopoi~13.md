## R01 (P1) — `IsEssential` holds for every geometric morphism, so the 5.6 headline and Roos's theorem are false as stated

**Location.** `TauCetiRoadmap/GrothendieckTopoi/Suggested.lean` lines 428–430: "def GeometricMorphism.IsEssential … : Prop := f.inverse.IsLeftAdjoint"; README line 864: "Define `GeometricMorphism.IsEssential` (`f.inverse.IsLeftAdjoint`: a further left adjoint `f_! ⊣ f^*` exists)"; the same name at README lines 208, 877 and 1026.

**Claim.** Mathlib's `Functor.IsLeftAdjoint left` (`Mathlib/CategoryTheory/Adjunction/Basic.lean` line 133) asserts that `left` has a *right* adjoint. For `f.inverse` that right adjoint is `f.direct`, with `f.adj : f.inverse ⊣ f.direct`, so every geometric morphism is `IsEssential` as declared. "A further left adjoint `f_! ⊣ f^*` exists" is `f.inverse.IsRightAdjoint` (line 138 of the same file). With the declared definition, `GeometricMorphism.isEssential_iff_preservesProducts` (lines 434–438) says that the inverse image of every geometric morphism between Grothendieck topoi preserves `u`-small products, and `exists_equiv_presheaf_iff_essential_points` (lines 466–472) says that a Grothendieck topos is a presheaf topos exactly when it has enough points. Both are refuted by the README's own Checks: the global sections morphism of `Sh(ℚ)` (5.6, Check 2: `Δ(∏ₙ Bool)` has the locally constant maps `ℚ → 2^ℕ` as global sections, `∏ₙ Δ Bool` the continuous ones, and `ℚ ↪ 2^ℕ` is continuous and not locally constant), and `Sh(ℝ)` (6.5, Check 2: the stalks reflect isomorphisms, yet `∏ₙ ∐ₖ ℓ(Iₙ,ₖ) ⟶ ⊤` is not an epimorphism, so it is not a presheaf topos). The README's route for 5.6 itself produces `IsRightAdjoint`: it applies `isRightAdjoint_of_preservesLimits_of_isCoseparating` to `f.inverse`.

## R02 (P3) — 4.4, Check 3 misidentifies the reversed comma category

**Location.** `TauCetiRoadmap/GrothendieckTopoi/README.md` lines 715–717: "Orientation: `Comma Φ (𝟭 G)` with `Φ` constant at the terminal object is the category of pointed objects of `G`, which has a zero object and so is not a Grothendieck topos unless degenerate."

**Claim.** Mathlib's `Comma L R` (`Mathlib/CategoryTheory/Comma/Basic.lean` line 67) has objects `(left : A, right : B, hom : L.obj left ⟶ R.obj right)`. For `L = Φ : F ⥤ G` constant at `⊤` and `R = 𝟭 G` the objects are `(B : F, A : G, ⊤ ⟶ A)` and the morphisms are pairs `(f : B ⟶ B', g : A ⟶ A')` with `g` preserving the points: the category is `F × Pointed(G)`, not `Pointed(G)`. It has no zero object unless `F` is degenerate (initial `(∅, (⊤, 𝟙))`, terminal `(⊤, (⊤, 𝟙))`). The conclusion survives: the map `(∅, (A, a)) ⟶ (∅, (⊤, 𝟙))` into the initial object is not invertible when `A ≇ ⊤`, which exists unless `G` is degenerate, and 1.2 makes every map into an initial object of a Grothendieck topos invertible.

**Witness.** The `Comma` fields quoted above; `Φ.obj B = ⊤` for every `B`, so `hom : ⊤ ⟶ A` and `B` is unconstrained.

**Repair.** Read: "Orientation: `Comma Φ (𝟭 G)` with `Φ` constant at the terminal object is `F × Pointed(G)`, pairs of an object of `F` and a pointed object of `G`; its initial object `(∅, (⊤, 𝟙))` receives the non-invertible map from `(∅, (A, a))` for any `A ≇ ⊤`, so it is not a Grothendieck topos unless `G` is degenerate (1.2)."
