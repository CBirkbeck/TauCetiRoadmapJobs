## R01 (P3) — The universal-section transversality in the §5.6 route is overstated as worded

**Location:** `TauCetiRoadmap/ImplicitAtlases/README.md:658`, §5.6: "the universal section (b, λ) ↦ s(b) + Σ λ_i σ_i(b) over B × ℝ^k is transverse to zero", after "finitely many sections σ_i of E with compactly supported cutoffs that span every fiber over a neighborhood of X".

**Claim:** the universal section is transverse to zero on all of B × ℝ^k, so that Sard's theorem applies to the projection of its zero set.

**Witness:** B = ℝ, E = ℝ², s(x) = (x, 0), X = {0}, U = (−1, 1). Take σ₁ = χ₁e₁ with χ₁ ≡ 1 on [−1, 3] and σ₂ = χ₂e₂ with χ₂ ≡ 1 on U and χ₂ ≡ 0 near 2, both compactly supported. They span every fiber over U. At (b, λ) = (2, (−2, λ₂)) the universal section is (2 − 2, 0) = 0, and its differential has image spanned by ∂_x ↦ (1, 0), ∂_{λ₁} ↦ (1, 0), ∂_{λ₂} ↦ (0, χ₂(2)) = 0: rank 1 < 2. Not transverse; the zero set near there is a half-plane glued to a line, not a manifold, so the Sard step has no manifold to apply to. The statement is true for the standard choice (on each of finitely many trivializing open sets covering X, one local frame multiplied by one cutoff supported in that set): wherever some σ_i(b) ≠ 0 the frame spans E_b, and elsewhere the value is s(b) ≠ 0.

**Repair:** say which choice is made: "a local frame on each of finitely many trivializing open sets covering X, each frame multiplied by one cutoff supported in its set", so that the σ_i span E_b at every b where one of them is nonzero; or restrict the claim to U × ℝ^k and choose λ regular and small enough that the zeros of s₁ lie in U (on the compact set (⋃ supp σ_i) ∖ U, |s| is bounded below). Tested on the witness: with one cutoff χ for both frame elements, the differential at any zero has ∂_{λ} image χ(b)·ℝ² = ℝ². In the same paragraph, "has zero set inside (⋃ supp σ_i) × [0, 1]" fails when rank E = 0 (no σ_i, zero set B × [0, 1], compact because B = X); write "inside (X ∪ ⋃ supp σ_i) × [0, 1]".

## R02 (P3) — The Euler-comparison API bullet drops "boundaryless", and the boundary version names hypotheses without a target

**Witness:** B = [0, ∞), E the trivial line, s(x) = x − 1. The zero-set atlas has X = {1}, ∂X = ∅, X_∅^reg = X, class 1 (Lemma 5.2.6 normalization). The two "boundary version" sentences give hypotheses (collar, transverse boundary restriction, perturbations away from a smaller collar) and no conclusion. On the citation: CharacteristicClasses §C2 item 3 (`TauCetiRoadmap/CharacteristicClasses/README.md:647–649` on main) states that a transverse zero locus represents the Euler class via Thom/Gysin with the twisted system o(E) of its Conventions (lines 165–173); the compact-support form on a noncompact base is carried by item 4's proper-embedding and compact-support Gysin convention (lines 665–672), not by item 3 alone.

**Repair:** write the bullet as "For a smooth section with compact zero set on a boundaryless base, …". Either state the boundary version as a target with its hypotheses and conclusion (section transverse along a product collar of ∂B, class equal to the pairing with the class relative to the boundary) or delete the two sentences. Cite "§C2 items 3 and 4" and say the form used: the Gysin image of the transverse zero locus in H^k_c(B; o(E)) is s₁^*U_E, which equals s^*U_E by the compactly supported homotopy.
