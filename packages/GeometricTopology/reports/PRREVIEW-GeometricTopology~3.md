## R03 (P2) — The genus formula of Layer 1.8 is false for closed surfaces

**Location:** `README.md:675–677`: "Define the genus of a compact connected orientable surface `F` as `(rank H₁(F; ℚ) − b + 1)/2` where `b` is the number of boundary components". **Witness:** for the torus, `rank H₁ = 2`, `b = 0`, and the formula gives `3/2`; for `S²` it gives `1/2`. The identity `rank H₁ = 2g + b − 1` holds only for `b ≥ 1`; for `b = 0` the rank is `2g`. The Checks (684–687) test only `b = 1`. Layers 4.3 and 9.1 use the genus of closed surfaces (the Heegaard surface, the capped Seifert surface). **Repair:** define the genus as `rank H₁(F; ℚ)/2` for `b = 0` and `(rank H₁(F; ℚ) − b + 1)/2` for `b ≥ 1` (equivalently `(rank H₁ − max(b, 1) + 1)/2`), and add the torus and `S²` as Checks.

## R04 (P2) — `Diff(M) → C(M, M)` is not a topological embedding for the `C^∞` topology

**Location:** `README.md:844–845`: "Prove that the evaluation map `Diff(M) × M → M` is continuous and that the restriction map `Diff(M) → C(M, M)` is a topological embedding." **Witness:** on `S¹`, `f_k(θ) = θ + k⁻² sin(kθ)` has derivative `1 + k⁻¹ cos(kθ) > 0`, so is a diffeomorphism; `sup |f_k − id| ≤ k⁻² → 0`, so `f_k → id` in the compact-open topology of `C(S¹, S¹)`, but `f_k'' = −sin(kθ)` does not converge, so `f_k ↛ id` in the weak `C^∞` topology (`Diffeomorph.weakWhitneyTopology`, defined as the subspace topology from `ContMDiffMap`'s compact-open `C^∞` topology). An injective continuous map whose inverse is discontinuous on the image is not an embedding. **Repair:** state that the forgetful map `Diff(M) → C(M, M)` is continuous and injective and that the `C^∞` topology is strictly finer than the compact-open one, with the family `f_k` as a negative-control Check.

## R05 (P2) — The HOMFLY-to-Alexander specialization has the wrong sign

**Location:** `README.md:1189–1190`: "`Δ_L(t) = P_L(1, −1, t¹ᐟ² − t⁻¹ᐟ²)`", with the HOMFLY relation `x P(L₊) + y P(L₋) + z P(L₀) = 0` (Conventions, 167–169) and the Conway relation `Δ(L₊) − Δ(L₋) = (t¹ᐟ² − t⁻¹ᐟ²) Δ(L₀)` (4.4, 1125–1126). **Witness:** substituting `x = 1`, `y = −1`, `z = t¹ᐟ² − t⁻¹ᐟ²` gives `Δ₊ − Δ₋ = −(t¹ᐟ² − t⁻¹ᐟ²) Δ₀`, the opposite sign. On the positive Hopf link (`L₋` the two-component unlink with `Δ = 0`, `L₀` the unknot): the Conway relation gives `Δ_H = t¹ᐟ² − t⁻¹ᐟ²`, the displayed specialization gives `t⁻¹ᐟ² − t¹ᐟ²`. The Jones specialization on the same line is consistent (`t⁻¹ V₊ − t V₋ = (t¹ᐟ² − t⁻¹ᐟ²) V₀` is `x = t⁻¹`, `y = −t`, `z = t⁻¹ᐟ² − t¹ᐟ²`), which shows the Alexander one is the slip. ## R06 (P3) — The two-strand torus-link Alexander polynomial is misprinted

**Location:** `README.md:1139–1141`: "`T(2, n)` has unnormalized Alexander polynomial `(1 + (−t)ⁿ)/(1 + t)`, which at `t = −1` equals `n`". **Witness:** at `t = −1` the displayed numerator is `1 + 1 = 2` and the denominator `0`; for `n = 3`, `(1 − t³)/(1 + t)` is not a polynomial.
