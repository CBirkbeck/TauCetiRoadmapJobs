## R01 (P3) — The two-point family does not exclude cotype q<2 or type p>2 "with any constant"

Location: `README.md` lines 1185–1186 ("no nonzero space has cotype q<2 or type p>2 (by the two-point family y,y)") and the third cotype Check, lines 1200–1202 ("the family (y,y) … excluding cotype q<2 with constant 1 and type p>2 with any constant").

Claim: the family (y,y) excludes type p>2 with any constant, and cotype q<2 with constant 1.

Witness: for (y,y), `R₂ = (½·‖2y‖² + ½·0)^(1/2) = √2‖y‖` and `(Σ‖y_i‖^p)^(1/p) = 2^(1/p)‖y‖`. Type p with constant C on this family reads `√2 ≤ C·2^(1/p)`, which holds for every C ≥ 2^(1/2−1/p); in ℝ with y = 1, p = 4, C = 2: 1.414 ≤ 2.378. Likewise cotype q with constant C reads `2^(1/q) ≤ C√2`, true for C ≥ 2^(1/q−1/2). The family refutes only constants below 2^|1/2−1/p|; it cannot refute "any constant". The statement "no nonzero space has type p>2" is true, but by the n-fold family.

Repair: in both places use the n-fold family (y,…,y): `R₂ = √n‖y‖` (the sign average of ‖Σε_i y‖² is n‖y‖²), against `n^(1/q)‖y‖` for cotype and `n^(1/p)‖y‖` for type, so `n^(1/q) ≤ C√n` fails for large n when q<2 and `√n ≤ C n^(1/p)` fails for large n when p>2, for every C. Keep (y,y) only as the constant-1 witness (2^(1/q) > √2 for q<2).
