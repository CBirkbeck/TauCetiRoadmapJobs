## C01 — `not_hasCantorAntichainOn_of_bfScattered` assumes countably many relation symbols, which neither its statement nor its route uses

In §4.1 (README line 585; `Suggested.lean` line 166) the theorem is stated "with countably many relation symbols". The route given there uses two things. The set of pairs `(f x, f y)`, `x ≠ y`, is analytic as the continuous image of an open subset of the square of Cantor space, which holds in any topological target (Mathlib `IsOpen.analyticSet_image`, `Mathlib/MeasureTheory/Constructions/Polish/Basic.lean` line 205, asks Polishness of the source only). Uniform back-and-forth separation is stated by CountableStructureSpaces §4.4 for every relational `L` (its `Suggested.lean` line 305 carries `[L.IsRelational]` alone). Countability is needed only for the added clause "and so is thin", which the Lean statement does not contain.

The rest of the roadmap keeps exactly this distinction: single-sentence splits (§4.4) and thinness from sentence cuts (§5.7) conclude "no Cantor antichain" for every relational `L` and "thin" with countably many symbols. As stated, a reader of §4.3 or §5.7 who wants "scattered implies no Cantor antichain" in an uncountable language finds a hypothesis that blocks it. The statement would be in line with its siblings if the instance were dropped from the Lean theorem and §4.1 read "a scattered `K` carries no Cantor antichain for isomorphism, and, with countably many relation symbols, is thin". If the hypothesis is kept on purpose, a clause saying so would do.

## C02 — The remark in §6.4 that the witness shows the one-sidedness of isolation to be "necessary" does not say what would fail

§6.4 (line 1219) says "the one-sidedness of isolation in §1.2 is necessary (isolation holds at the rank of the code of `M`, which exceeds `ω`, not at that of the other codes)", and the warning of §1.2 (line 335) ends "Do not state isolation symmetrically". Back-and-forth equivalence and isomorphism are both symmetric, so the isolation field `bfEquivSetoid (ρ c) c d → c ≅ d`, quantified over all `c` and `d`, is equivalent to its mirror image with `ρ d` at the level: the two-sided form a reader would first write is the same contract. In the witness, every isolating rank also exceeds `ω` at the code of each `N_z` (it is `ω`-equivalent and not isomorphic to the code of `M`), so the example does not separate the code of `M` from "the other codes" either.

What the example does show is the sentence's other half and the item before it: level `ω`, the internal Scott rank of `M`, does not isolate the code of `M`. The remark would be clear if it said that, or if §1.2 named the symmetric statement it warns against (for instance "equivalence at the rank of `c` decides isomorphism between any two codes in the level class of `c`", which the witness would refute only for a rank equal to `ω` at `M`).
