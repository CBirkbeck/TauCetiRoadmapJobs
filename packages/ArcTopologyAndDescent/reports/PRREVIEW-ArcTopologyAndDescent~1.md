## R01 (P2) — §9.10's integral-map clause does not satisfy the target's hypothesis

**Location.** `TauCetiRoadmap/ArcTopologyAndDescent/README.md` line 1284: "In particular this applies to integral maps of t-torsion-free rings inducing an isomorphism after inverting t."

**Claim.** An integral map A→B of t-torsion-free rings with A[1/t]≅B[1/t] induces A^tic≅B^tic, so the stated target (hypothesis A^tic≅B^tic) covers it. This is copied from BM21 line 2296.

**Witness.** Over a field k let A be the k-span of the monomials t^e·x^k with e ≥ ⌈√k⌉ inside k[t,x], and B = k + t·k[t,x]. Then A ⊆ B, B = A[t·x^n : n ≥ 1], and (t·x^n)^n = t^n·x^(n²) ∈ A, so B is integral over A; both are domains, and A[1/t] = B[1/t] = k[t,t⁻¹,x]. For x ∈ B[1/t]: t·x^n ∈ B for every n, so x ∈ B^tic; but t^c·x^n ∈ A needs c ≥ ⌈√n⌉ for every n, so x ∉ A^tic. Hence A^tic ⊊ B^tic, and the integral map is not an instance of the stated hypothesis.

**What is true.** The cartesian square still holds for such maps: BM21's proof (line 2298 onward) uses the hypothesis only through "every b ∈ B has a uniform power-of-t denominator bound on its powers in A", that is B ⊆ A^tic inside A[1/t] = B[1/t], and an integral element of A[1/t] always has such a bound (if x satisfies a monic equation of degree m with x = a/t^k then t^(k(m−1))·x^n ∈ A for all n). So the integral case follows from the proof, not from the stated theorem.

**Repair (tested on the witness).** State §9.10 as: let A→B carry the nonzerodivisor t to a nonzerodivisor, induce A[1/t]≅B[1/t], and satisfy B ⊆ A^tic (every element of B has t^c·b^n ∈ A for one c and all n); then the square is cartesian for every small-limit-valued arc-sheaf. Record the two instances as consequences: A^tic≅B^tic (since B ⊆ B^tic = A^tic) and integral A→B (by the bound above). Add the witness ring pair above as a negative Check: integral, equal after inverting t, but A^tic ≠ B^tic. On the witness, B ⊆ A^tic holds (each t·x^n satisfies (t·x^n)^m ∈ A for m ≥ n, so with c = n the bound holds), so the repaired statement applies to it while the original hypothesis fails. Also note in the route that A′ = B ×_(B/tB) A/tA is not a subring of B when A ∩ tB ≠ tA (example: A = k[t, tx, x²] ⊂ B = k[t,x], where tx ∈ A ∩ tB but x ∉ A); the argument still works because A′→B has nil kernel and A→A′ is integral with A′[1/t] = A[1/t].

## Source issues

- **Error** in BM21 at Theorem 6.25, remark after the statement, printed p. 55 (line 2296): the source says integral maps of t-torsion-free rings with the same t-localization satisfy A^tic ≅ B^tic; it should say they satisfy B ⊆ A^tic, which is all the proof uses, since A^tic ⊊ B^tic occurs (witness in R01); affects a stated result (the remark; the theorem's conclusion survives under the weaker hypothesis).
- **Gap** in BM21 at Theorem 6.25, proof, printed p. 55 (line 2302): the source says every element of A′ = B ×_(B/tB) A/tA is a + tb inside B; it should note that A′→B need not be injective when A ∩ tB ≠ tA (A = k[t,tx,x²] ⊂ k[t,x]) and argue with the nil kernel; affects the proof.
- **Error** in BM21 at Lemma 4.3, printed p. 25 (line 1040): the source says pW is prime and contracts to p whenever pW ≠ W; it should also assume ker(V→W) ⊆ p, as the proof's reduction to V ⊆ W presupposes (for p strictly below the kernel, pW = 0 contracts to the kernel); affects a stated result.
