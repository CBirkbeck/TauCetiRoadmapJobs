## R01 (P2) — `exists_normalizedMellinContinuation` assumes analyticity, not smoothness

Location: `TauCetiRoadmap/DirichletPadicLFunctions/Suggested.lean` line 56, `hsmooth : ContDiffOn ℝ ⊤ f (Set.Ici 0)`; README §0.1 line 170, "assume smoothness within J of every order", and line 172, "its smoothness is `ContDiffOn` on the closed half-line".

Claim: the Lean headline states RJW Theorem 2.4 for every smooth, rapidly decreasing `f`.

Witness: at the pinned Mathlib, `⊤ : WithTop ℕ∞` is the analytic order `ω` (`Mathlib/Analysis/Calculus/ContDiff/Defs.lean` line 90: "`⊤ : ℕ∞ω` with `ω`"; line 122: "For `n = ω`, we require the function to be analytic"; `FTaylorSeries.lean` line 117 defines the notation). The probe `example (h : ContDiffOn ℝ ⊤ f (Set.Ici 0)) : ContDiffOn ℝ ω f (Set.Ici 0) := h` elaborates. RJW Theorem 2.4 (arXiv text line 409) assumes only a `C^∞` function with exponentially decaying derivatives. So the Lean theorem is true but states a strictly narrower result than the README and the source: every `C^∞` non-analytic test (a compactly supported bump on `[0,∞)` times `e^{-t}`) is excluded, and the README's generality no longer equals the Lean's.

Repair, tested: write the hypothesis as `ContDiffOn ℝ ∞ f (Set.Ici 0)` under `open scoped ContDiff` (or `ContDiffOn ℝ ((⊤ : ℕ∞) : WithTop ℕ∞) f (Set.Ici 0)`). A copy of the file with this signature elaborates against the pins with `sorry` as its only warning. The two kernel headlines (§§0.2–0.3) need no change: `bernoulliKernel` and `smoothedMellinKernel` are real analytic, so they satisfy either hypothesis.

## R02 (P3) — a §4.4 Check names the wrong discriminating value

Location: README §4.4 line 1040, "At p=2,x=2 the reflection sign is +1; the odd-prime formula using only x modulo 2 would give −1."

Claim: the Check separates the dyadic reflection formula from the odd-prime one.

Witness: the odd-prime formula `(−1)^{R(x)}` with `R(x) ∈ {1,…,p}` gives, at `p=2, x=2`, `R(2)=2` and `(−1)^2 = +1`, the same as the dyadic formula `(−1)^{1+x₁}` with `x₀=0, x₁=1`; both agree with `Γ_2(2)Γ_2(−1) = 1·1 = 1` (`Γ_2(−1)=1` from `Γ(0) = −(−1)Γ(−1)`). The two formulas separate at `x=3`: `Γ_2(3)Γ_2(−2) = (−1)(−1) = +1` (`Γ_2(3) = −1`, `Γ_2(−2) = −Γ_2(−1) = −1`), the dyadic formula gives `(−1)^{1+1} = +1`, the odd-prime formula `(−1)^{R(3)} = (−1)^1 = −1`.

Repair: replace the Check by "At p=2, x=3 the reflection sign is +1 (`Γ_2(3)Γ_2(−2) = (−1)(−1)`), while `(−1)^{R(3)} = −1`; at x=2 both formulas give +1."
