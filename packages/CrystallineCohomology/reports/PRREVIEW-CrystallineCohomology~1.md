**Witness.** `TauCetiRoadmap/JacobianChallenge/README.md` lines 139–141 on main state genus g := dim H¹(O), Riemann–Roch and Serre duality with the relative dualizing sheaf ω_{X/k} and deg ω = 2g − 2; the symbol Ω¹ occurs nowhere in that README. The identification ω ≅ ∧^d Ω for smooth f is `relativeDualizingModule_smooth` in SchemeAndStackFoundations §2.20 (its README line 4350), a supplier this roadmap already cites.

**Repair.** In the JacobianChallenge contract claim only genus, Riemann–Roch and Serre duality with ω_{X/k}; add SchemeAndStackFoundations §2.20 `relativeDualizingModule_smooth` for ω_{C/k} ≅ Ω¹_{C/k}; in the CR.3.5 curve target derive h⁰(Ω¹) = h¹(O) = g from the two.
