## R01 (P3) — The level-H Check of §4.7 does not witness its conclusion

**Location.** `TauCetiRoadmap/GSp4NonregularModularityLifting/README.md` line 883 (fifth Check of §4.7), ending "Hence at this level Δ∨ is not Δ composed with a normalizing element, and the two-correspondence recurrence is required"; and the prose claim at line 871, "it is neither Δ nor Δ composed with the action of an element of SL₂(ℤ/N) normalizing Γ".

**Claim.** For Γ = {γ ≡ I mod 3, γ mod 5 ∈ H}, H = ⟨A⟩ of order six in SL₂(𝔽₅), and p = 7, the reverse correspondence Δ∨ = Γ diag(1,7) Γ cannot be obtained from Δ = Γ diag(7,1) Γ by a normalizing element, so the two-correspondence recurrence is forced at this level.

**Witness.** The transport the roadmap itself uses (line 877, at principal level) is conjugation, Γ diag(1,p) Γ = n Γ diag(p,1) Γ n⁻¹. The Check only excludes one-sided compositions nΔ and Δn (D∨ ∉ N(H)DH and D∨ ∉ HDN(H), both true, verified by exhaustive computation in SL₂(𝔽₅)). It does not exclude conjugation: n̄ = [[0,2],[2,0]] ∈ SL₂(𝔽₅) normalizes H and n̄ D̄ n̄⁻¹ = D̄∨ exactly (D̄ = diag(2,1), D̄∨ = diag(1,2)). Any n ∈ SL₂(ℤ) with n ≡ n̄ mod 5 and n ≡ I mod 3 normalizes Γ, and since Γ ⊇ Γ(15) with (7,15) = 1, a Γ(15)-double coset of a determinant-7 matrix is determined by its residue mod 15 (strong approximation for Γ⁰(7)), so Γ D∨ Γ = n Γ D Γ n⁻¹ at this level. The six conjugates n_j A n_j⁻¹ displayed in the Check are numerically right; only the conclusion drawn from them is not. By contrast, for H₁ = unipotent upper triangular (the Γ₁(5)-type level) the conjugation model is excluded (every n ∈ N(H₁) = Borel gives n D n⁻¹ upper triangular with (1,1) entry 2, so H₁(nDn⁻¹)H₁ ∌ diag(1,2)), while there D∨ ∈ N(H₁)DH₁ does hold, so the one-sided test would wrongly pass. The Check therefore tests a model different from the one the target uses.

**Repair.** Replace the fifth Check by: Γ = Γ(3) ∩ Γ₁(5) (neat, level dividing 15), p = 7; mod 5 the residual group is the unipotent H₁ of order 5 with normalizer the Borel B; for n ∈ B the conjugate n D n⁻¹ is upper triangular with (1,1) entry ≡ 2, hence every element of H₁ (nDn⁻¹) H₁ has (1,1) entry 2, while D∨ ≡ diag(1,2) has (1,1) entry 1; so Γ D∨ Γ ≠ n Γ D Γ n⁻¹ for every n normalizing Γ, and the reverse correspondence is a second operator at this level. Rewrite line 871 to "at a general neat tame level Δ∨ need not be a conjugate of Δ by an element normalizing Γ (it is one at principal level), and no such identification is assumed". The target of §4.7 (reciprocity between F_Δ and F_Δ∨ and the two-correspondence recurrence) is unchanged and remains the right general statement.
