## R01 (P1) — Axler's cubic Mertens product is false on (1.983, 2)

Location: `TauCetiRoadmap/ExplicitMultiplicativeFunctions/README.md:3372–3374` ("e^γ (log x) ∏_{p ≤ x} (1 − 1/p) < 1 + 0.07/log³ x for every real x > 1"), `README.md:825–826` (*MertensProductCubicRangeVerified*: "for every real x with 1 < x < 392 687"), `README.md:3366–3368` ("from which 0.07 follows"), and `Suggested.lean:311–312` ("On 1 < x < 392 687 the inequality is a direct verification").

Claim: the upper bound with `0.07/log³ x` holds for every real `x > 1`, and the stretch `1 < x < 392 687` is a direct verification.

Witness: at `x = 1.99` the product over primes `≤ 1.99` is empty, so the left side is `e^γ log 1.99 = 1.22562`, while `1 + 0.07/log³ 1.99 = 1.21482`. The inequality fails on `(1.983, 2)` (at `1.983`: `1.21934 > 1.21816`; at `1.98` it still holds). The proposition *MertensProductCubicRangeVerified* is therefore false, and the README's 8.1 display and the Lean docstring assert a false statement. Axler's unexpanded form `exp(η_A(x) + 1.02/((x − 1) log x))` is huge near `x = 1` and does hold there; the expansion to `0.07` is the README's own step and only holds from `2` on.

Repair (tested: the maximum of `e^γ log x ∏_{p ≤ x}(1 − 1/p)` over `[2, 10^6]` is `0.99997`, so the bound holds on `[2, 392 687)` with margin, and on `[2, 3)` the value is at most `e^γ (log 3)/2 = 0.978`):
- README 8.1 first display: replace "for every real x > 1" by "for every real x ≥ 2".
- README 8.1 "from which 0.07 follows": write "from which 0.07 follows for every x ≥ 2 (on (1.983, 2) the expanded form fails, Checks)".
- README 0.7 *MertensProductCubicRangeVerified*: replace "for every real x with 1 < x < 392 687" by "for every real x with 2 ≤ x < 392 687".
- README 8.1 "The ranges 1 < x < 392 687 (upper bound)": replace by "2 ≤ x < 392 687".
- Add the negative control to the 8.1 Checks: "`x = 1.99`: `e^γ log 1.99 = 1.2256 > 1 + 0.07/log³ 1.99 = 1.2148`, so the cubic form needs `x ≥ 2`, unlike the pair of Theorems 7–8, which holds on `(1, 2)`."
- `Suggested.lean:311–312`: "On `2 ≤ x < 392 687` the inequality is a direct verification (README 8.1)."
