## REV-DESIGN-NashBlowups~4/R01 (P1) — applied

Verified. In characteristic 3, `df = −3x² dx + 2y dy = 2y dy`, and `y` is a unit on `X_sm`, so `dy = 0` and
`Φ = [1 : 0]`. In characteristic 2, `df = x² dx`, so `Φ = [0 : 1]`. In both cases the graph closure is `X × {Φ} ≅ X`,
with ring `k[t², t³]`.

Old → new: §3.1 Check "For the cusp, `Φ(t) = [1 : 3t/2]` … `≅ 𝔸¹`" → restricted to characteristic `0` or `≥ 5`
(`3/2` is a unit; in characteristic 5 the coordinate is `4t`), plus a new negative-control Check for characteristics
2 and 3. `plan.json` 3.1: `gauss_cusp` is restricted the same way, and a new test `gauss_cusp_small_char` is added.

Pattern: every other `3t/2` and cusp computation was rechecked:
- §2.1, §2.4, §2.5 and the §4.4 Examples are already scoped to characteristic `0` or `≥ 5`, or to `ℚ`.
- The §0.6 embedding-dimension Check and the Layer 0 Examples fibre count (`ℙ¹` over the origin, a point elsewhere)
  hold in every characteristic. Away from the origin, `x` and `y` are both nonzero, so the relation is nonzero in
  characteristics 0, 2, 3 and `≥ 5`.

## REV-DESIGN-NashBlowups~4/R02 (P1) — applied

Verified. Take `n = 0` and `f = 0`. Then `X = Spec k` is pure of dimension `0 = n − 1` in `ℕ`, while `J_f = 0`. So
`Bl_0 X = ∅`, but `X* = Spec k`.

Old → new: §3.3 "let `f ∈ k[x_1, …, x_n]`" → "let `n ≥ 1` and `f ∈ …`". A new Check covers `n = 0, f = 0` as the
negative control and `n = 1, f = x_1` (both sides `Spec k`). `plan.json` 3.3: the statement gains `n ≥ 1`,
the hypotheses gain `1 ≤ n`, and a new test `hypersurface_ambient_zero` is added.

Pattern:
- No other target subtracts naturals in a hypothesis. The `β − α` in §5.1 is guarded by `α ≤ β`, and `q − 1` is safe
  now that `q ≥ 2`.
- The §3.2 zero-ideal Check now says "for nonempty `X`", since `X = ∅` gives `∅ = ∅`, and it gives the reason
  `Bl_0 = ∅`: the Rees algebra of the zero ideal has no part of positive degree.
