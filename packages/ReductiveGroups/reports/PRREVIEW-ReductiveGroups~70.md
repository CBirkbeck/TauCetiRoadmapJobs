## R02 (P3) — The §6.2 Check miscounts the components of the constant group ℤ/ℓ

**Location.** README line 1454: "the constant group ℤ/ℓ for a prime ℓ≠p is smooth and linearly reductive (Maschke) but has two components and is not a torus".

**Claim.** The constant group ℤ/ℓ has two components.

**Witness.** The constant group scheme ℤ/ℓ over k is ⊔_{ℓ copies} Spec k: it has ℓ connected components, and π₀ has degree ℓ (the roadmap's own §3.2 bullet, line 745: "π₀(G) has degree equal to the number of geometric connected components"). For p = 2 the smallest admissible ℓ is 3, with three components; the sentence is true only for ℓ = 2, which the hypothesis ℓ ≠ p excludes in characteristic 2.

**Repair.** "but has ℓ components and is not a torus" (the Lean docstring at Suggested.lean line 185 is correct as written and needs no change).
