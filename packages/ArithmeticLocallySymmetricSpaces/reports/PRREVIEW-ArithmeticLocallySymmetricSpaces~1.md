## R04 (P3) — `IsCartanInvolution` is defined more generally than the README states

**Location.** `TauCetiRoadmap/ArithmeticLocallySymmetricSpaces/Suggested.lean` line 44, `def IsCartanInvolution {H : CommHopfAlgCat ℝ} (θ : H ≅ H) : Prop`; README line 1072, "Let `H` be a connected linear algebraic group over `ℝ`".

**Claim.** The Lean predicate accepts every commutative real Hopf algebra, of any type; compactness is taken in the product topology on `H → ℂ`. For finite-type `H` this is the usual topology on complex points (the projection to a finite generating set is a homeomorphism onto the image), which is what the docstring asserts; for non-finite-type `H` the predicate is a different notion the README never names. The two theorems carry `FiniteTypeCommHopfAlgCat ℝ`, so nothing stated is wrong.

**Witness.** Elaborated type: `@IsCartanInvolution : {H : CommHopfAlgCat ℝ} → (H ≅ H) → Prop`.

**Repair.** Either take `{H : TauCeti.FiniteTypeCommHopfAlgCat ℝ} (θ : H.obj ≅ H.obj)` in the definition, or add one sentence to ALS.0.1 saying the predicate is defined for every affine real group scheme with the evaluation topology and agrees with the usual notion in finite type.

## Source issues

- **Misprint** in NT16 at Lemma 4.6, pp. 59–60 (arXiv v1 p. 39): the correspondence between the `Y`-variables of `GL_n` and the `Z`-variables of the blocks carries the factor `q_v` to the power `(n_{i+1}+⋯+n_s) − (n_1+⋯+n_{i−1})`; it should be half that exponent (the `GL_2` generator check gives `qZ₁ + Z₂` only with exponents `±1/2`); affects the proof (the final twist `ε^{−(n_{i+1}+⋯+n_s)}` is unaffected).
