1. **F01** (P2) Direction of the W_d action on the rescaled field is inverted

   **Location.** `packages/ConstructiveFieldTheoryPhi4/design/README.md` line 626 (7.1, API): "For g ∈ W_d and a g-invariant V, `T_{f∘g,L,Σ}(φ) = T_{f,L,Σ}(φ ∘ g)`."

   **Claim.** The rescaled field of the pulled-back test function equals the rescaled field of the pulled-back configuration, with the same g on both sides.

   **Witness.** Compute both sides from the definition `T_{f,L,Σ}(φ) = Σ^{−1/2} Σ_x f(x/L) φ_x`: the left side is `Σ^{−1/2} Σ_x f(gx/L) φ_x = Σ^{−1/2} Σ_y f(y/L) φ_{g⁻¹y}`, the right side is `Σ^{−1/2} Σ_x f(x/L) φ_{gx}`. Instance: d = 2, L = 1, Σ = 1, V = {0, ±e₁, ±e₂} (W_2-invariant), g the rotation (x₁, x₂) ↦ (−x₂, x₁) (an element of W_2 of order 4, so g ≠ g⁻¹), f equal to 1 at e₁ and 0 at the other four lattice points. Left side: `φ_{g⁻¹e₁} = φ_{−e₂}`. Right side: `φ_{ge₁} = φ_{e₂}`. These differ for the configuration φ = 1_{e₂}. The identity holds only when g = g⁻¹ (d = 1, and every reflection), which is why the Check in 7.3 ("d = 1: W_1 = {±1}") does not detect it.

   **Repair.** Replace the bullet by "For g ∈ W_d and a g-invariant V, `T_{f∘g,L,Σ}(φ) = T_{f,L,Σ}(φ ∘ g⁻¹)`; equivalently `T_{f,L,Σ}(φ ∘ g) = T_{f∘g⁻¹,L,Σ}(φ)`." Tested on the instance above: left side `φ_{g⁻¹e₁} = φ_{−e₂}`, right side `Σ_x f(x) φ_{g⁻¹x} = φ_{g⁻¹e₁} = φ_{−e₂}`; equal. The invariance statement of 7.3 ("`(T_{f∘g}(Φ))_f` has the same law as Φ") is unaffected, because W_d is a group and the lattice data (boxes, blocks, nearest-neighbour coupling) are invariant under g and g⁻¹ alike; no other target consumes the bullet's direction. Add the instance above as a Check of 7.1 (a plausible wrong definition, the one with g on both sides, gets `φ_{e₂}` instead of `φ_{−e₂}`).

2. **F02** (P3) Two-site Gaussian stability Check omits the antiferromagnetic side

   **Location.** `packages/ConstructiveFieldTheoryPhi4/design/README.md` line 200 (1.5, Checks): "Two sites with `J_{xy} = J`: stable iff `J < 2|b|`, and then `⟨φ_xφ_y⟩ = J/(4b² − J²)` …".

   **Claim.** The two-site Gaussian triple is stable exactly when J < 2|b|.

   **Witness.** 1.5 is stated for an arbitrary coupling J on V (signs allowed; the stability criterion is "`2|b| I − J⁰` positive definite", which 1.1 and 1.5 do not restrict to J ≥ 0). For J = −3|b| the matrix is `[[2|b|, 3|b|], [3|b|, 2|b|]]` with determinant `4b² − 9b² < 0`, not positive definite, so the triple is unstable although `J < 2|b|`. The formulas `J/(4b² − J²)` and `2|b|/(4b² − J²)` are correct on the stable set `|J| < 2|b|` (inverse of `[[2|b|, −J], [−J, 2|b|]]`).

   **Repair.** Write "stable iff `|J| < 2|b|`" (or add "for J ≥ 0" to the Check). Tested: J = −3|b| is now excluded; J = |b| gives `⟨φ_xφ_y⟩ = 1/(3|b|)`, consistent with the general criterion.
