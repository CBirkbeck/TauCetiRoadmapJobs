1. **F01** (P2) §8.2's prismatic package drops the filtered structure of `c`, and the finite-stage bullet is then refuted by its own Check object

   **Location.** `design/README.md` line 679: "c a φ_A-semilinear map `H^{≥0} → N^{≥0}`"; line 682: "the restriction of `can − cφ` to `N^{≥j}{i}/p → N^{≥j−i}{i}/p` factors, canonically and functorially, as an automorphism … followed by `can`"; line 690 (Check): "With j = 3 …, `can : N^{≥3}/2 → N^{≥2}/2` is zero". plan.json 8.2 statement and test `F2_weight1`.

   **Claim.** For every object of the README's `C_A` (c unfiltered), the restricted mod-p map factors as an automorphism of `N^{≥j}{i}/p` followed by `can : N^{≥j}{i}/p → N^{≥j−i}{i}/p`.

   **Witness.** akn-delta Definition 8.1, line 1703: `c : H → sc_p(N)` is a map of `(ℕ,≥)×ℤ`-filtered modules, `sc_p(N) = N^{≥p·⋆} ⊗ p^⋆ℤ` (Construction 7.3, line 1557–1565; lines 1689–1699 give the mod-p map `sc_p(N)/p → N^{≥p⋆}/p`). The proof of Lemma 8.5 (line 1763–1769) starts from exactly this: "mod p we have a morphism `c : H^{≥⋆}/p → N^{≥p⋆}/p`", which supplies the lift `l : H^{≥j−i} → N^{≥p(j−i)} → N^{≥j}` because `p(j−i) > j`. Definition 1.1 (line 98), which the README cites, says `c` carries "certain extra structure which we will suppress for simplicity here"; the README copied the simplified form. Computed on the README's own Check object (absolute package of 𝔽_2, `Δ̂ = ℤ_2`, `N^{≥n} = 2^nℤ_2`, `cφ(2a) = a` as the README fixes it at line 690), `i = 1`, `j = 3`, bound `3 > 2` satisfied: `N^{≥3}/2 = 8ℤ_2/16ℤ_2 ≅ 𝔽_2`, `N^{≥2}/2 = 4ℤ_2/8ℤ_2 ≅ 𝔽_2`; `can(8b) = 8b ∈ 8ℤ_2`, zero; `cφ(8b) = 4b`, nonzero for b odd; so `can − cφ = −cφ` is an isomorphism `𝔽_2 → 𝔽_2` and no automorphism α gives `can ∘ α = can − cφ` (left side zero). With the sc_p structure the mod-p `cφ` into `N^{≥j−i}/p` is the composite through `N^{≥p(j−i)}/p = N^{≥4}/2`, and `can : N^{≥4}/2 → N^{≥2}/2` is zero (`16b ∈ 2·4ℤ_2`), so the lemma holds trivially there; without it the bullet is false, and it is not even well-formed (nothing in the README's axioms puts `cφ(N^{≥j})` in `N^{≥j−i}`).
